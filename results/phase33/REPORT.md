# Phase 33 — 0.25倍速の水っぽさの原因調査

## 結論と採否

**水っぽさを支配する単一の原因は未特定。改善方式は採用しない。** Phase 31方式Bを0.25倍速の比較基準として維持するが、ユーザーがMIX全体とDrumsの余韻に水っぽさを認めており、音質は未合格である。Phase 32のB1（位相ロックOFF）、B2（イベント位相リセットOFF）、B3（毎フレーム入力位相へ再同期）はいずれも不採用。ユーザーの「以前より悪化した」という評価は重視するが、どのB方式がどれほど悪化したかは今回の回答だけでは分からない。

今回の実装は**研究用の非破壊的な計測器**と比較音源の整理だけである。Phase 5.3 Experimental 3500、Phase 30の正式DSP・再生・キャッシュ・シーク、Phase 12/28 Golden、Phase 31 Bの参照WAVを変更していない。新しい位相補正、TimeMap、音質アルゴリズムは追加していない。

## 元音源と方式の再照合

Phase 32の[raw一覧](raw_audit.csv)の**74/74本**を既存manifestのSHA-256と再照合した。そのうちPhase 31 Bに相当する0.25/0.30倍速の**14/14本はPhase 31のrawとバイト一致**。Phase 32の短区間試聴WAVもrawから同じ切り出し、全方式共通ゲイン0.5、両端3 msフェードで再生成し、**19/19本のSHA-256が一致**した。[照合表](audition_audit.csv)。従って今回確認した範囲では、方式名・試聴ファイルの取り違えや再生成による内容変化は見つからなかった。非公開音源とWAVはGit管理対象外で、ハッシュ・計測表を保持する。

| 名称 | Phase 31/32内の実体 | この調査での扱い |
|---|---|---|
| Phase 31 B / A | `baseline`、半分の解析ホップ、位相ロック・イベント位相リセットあり | 唯一の0.25倍速比較基準。音質未合格 |
| Phase 32 B1 | `no_lock`、位相ロックだけOFF | 不採用 |
| Phase 32 B2 | `no_reset`、イベント時の位相リセットだけOFF | 不採用 |
| Phase 32 B3 | `no_propagation`、毎フレーム入力位相へ再同期 | 不採用 |

## 計測方法と読み方

同じ入力・共通ゲインで、Drumsの**入力3.77–4.02秒のアタック**と**4.05–4.35秒の余韻**、MIXの**2.9–4.2秒の重畳部**と**4.2–4.8秒の静穏部**を別々に調べた。Midの実TimeMapを逆引きし、入力の局所RMS包絡を出力時刻へ対応させた。包絡誤差は一定のゲイン差を除いたdB偏差であり、小さいほど入力包絡に近い。ただし元音源には演奏・残響・音源間の重なりがあり、包絡誤差だけで聴感を決められない。[区間・帯域・ステレオ表](region_diagnostics.csv)、[アタック表](attack.csv)。

研究用[位相トレース](../../src/prototype/Phase33TraceEngine.cpp)はPhase 32エンジンの独立複製から各解析フレームの入力位置、出力位置、合成ホップ、リセット、前フレームとの入力位相変化、出力位相変化、ピーク所有領域の変更を記録する。[集計表](phase_summary.csv)。ここでいう「位相残差」は、実際の出力位相変化と**位相ロック前の瞬時周波数伝播による予測値**との差である。位相ロックが意図的に非ピークbinを動かす場合にも大きくなるため、残差の大きさをそのままアルゴリズムの計算誤りとは解釈しない。計測付きレンダリングの**16/16本は元のrawとSHA-256で一致**し、実音源8条件のイベント数とTimeMapハッシュも一致した。[トレース監査表](trace_audit.csv)。

Low/Mid/Highの各未加工合成出力と、LP250・LP3500の後で実際に最終音声へ加算される帯域寄与を分けた。後者は `LP250(low)`、`LP3500(mid)-LP250(mid)`、`high-LP3500(high)`。3本の和と正式な最終出力との差は全8条件で最大**1.32×10⁻⁶未満**（float演算順による差）である。[再構成表](crossover.csv)、[250/3500 Hz近傍の位相・包絡表](crossover_regions.csv)。研究用分解器は正式DSPのFIR係数・境界処理を使用し、正式DSPは変更していない。

## Drums：アタックと余韻

| 0.25倍速の余韻、入力4.05–4.35秒 | Phase 31 B | B1 | B2 |
|---|---:|---:|---:|
| 入力に対する最終音声の包絡誤差、dB | 3.60 | 4.68 | 3.91 |
| 包絡相関 | 0.922 | 0.862 | 0.908 |
| Side/Mid | 0.260 | 0.285 | 0.584 |

Phase 31 Bでも入力の自然な減衰から時間方向にずれる。B1は位相ロック由来の出力位相残差を大幅に減らす一方、余韻包絡は悪化した。B2はSide/Midが約2.25倍で定位の副作用が大きい。アタック位置はMid TimeMapで対応づけ、入力の10 ms包絡の最も急な立ち上がりを起点とした。Bのピーク位置は約+8.8 ms、ピーク0.979、前20 ms/後20 ms RMS比0.064。B2は約+23.0 ms、ピーク1.135、前後比0.908となり、強い前響き・タイミング変化を示した。これを余韻改善として採用できない。[詳細](attack.csv)。

Phase 31 Bの余韻について、出力位相残差のフレーム中央値はLow/Mid/Highで**1.37/1.17/1.14 rad**、ピークbinだけでは**0.039/0.059/0.035 rad**だった。ピーク所有領域の変更を受けたbinの残差は、所有領域が変わらないbinより大きい。つまり非ピークbinの位相関係がフレーム間で動くという**検討に値する機構**は見える。一方、B1では各帯域の残差が約0.05–0.07 radになっても、余韻包絡と他の持続音が悪化した。**位相ロックを全面的に外すことは原因の解決にならない。** 位相残差と聞こえる水っぽさの因果関係も、まだ証明できていない。[全フレーム集計](phase_summary.csv)。

余韻の最終波形におけるL/R相関はB **0.885**、B1 **0.862**、B2 **0.498**。周波数帯別の左右位相差のRMSはBのLow/Mid/Highで**0.401/0.444/0.503 rad**、B2では**0.842/1.268/1.117 rad**に拡大した。レベル差（ILD）はBの3帯域で**1.81/1.41/1.30 dB**、B2で**1.73/1.44/1.30 dB**と近く、B2のSide/Mid増大は単なる左右レベル差より位相関係の変化と整合する。位相差は有効な時間周波数binを振幅で重み付けした集計であり、[有効bin数を含む表](region_diagnostics.csv)に記録した。

帯域別の入力包絡誤差は、Phase 31 BのDrums余韻で生Low/Mid/Highが**2.66/4.07/5.69 dB**、FIR後の各寄与が**3.02/4.03/5.68 dB**、最終音声の同帯域が**2.71/3.99/5.62 dB**。特に高域ではFIR合成前から揺れがある。クロスオーバーが全ての揺れを新規に作ったという説明は支持されない。ただし高域の5.69 dBには入力の自然な残響・ノイズ変動と時間対応の誤差も入る。3500 Hz近傍では生Mid/High間の位相集中度が0.284、FIR後が0.270で、帯域間の位相が散る。これは拡散したシンバル余韻でも起こり得るため、値だけで異常とは判定しない。

## MIX：重畳部・静穏部と帯域間合成

| 区間 | Phase 31 B 包絡誤差 / 相関 | B1 包絡誤差 / 相関 | 生Low/Mid/Highの帯域包絡誤差 | FIR後Low/Mid/Highの帯域包絡誤差 |
|---|---:|---:|---:|---:|
| 重畳部 2.9–4.2秒 | 1.12 dB / 0.880 | 2.59 dB / 0.607 | 1.18 / 0.78 / 1.81 dB | 1.18 / 0.80 / 1.81 dB |
| 静穏部 4.2–4.8秒 | 1.00 dB / 0.972 | 2.15 dB / 0.870 | 1.51 / 0.92 / 0.95 dB | 1.56 / 0.89 / 0.92 dB |

MIXでも最終音声の揺れの相当部分はFIR前の各解像度出力に既にある。250 Hz付近の重畳部では生Low/Midの位相集中度0.615、FIR後0.725。3500 Hz付近では生Mid/Highの0.212、FIR後0.056と時間方向に散り、FIR後の帯域間包絡比の標準偏差は**11.9 dB**。ただしこの比は各FIR寄与が小さくなる時間窓で大きく動き、波形加算による大きな打ち消しが増えたことまでは示さない。同じ区間の加算量指標の下位10%は生0.351、FIR後0.595であり、少なくともこの測定ではFIRが強い相殺を増やしたという仮説は支持されない。クロスオーバー近傍の実際の聴感上の寄与は未特定。[全区間・方式](crossover_regions.csv)。

MIX重畳部のBのL/R相関は**0.866**、Side/Midは**0.270**、Low/Mid/Highの左右位相差RMSは**0.214/0.738/0.681 rad**。静穏部はL/R相関**0.636**、Side/Mid**0.472**で、元のステレオ残響の影響も大きい。B1やB2との数値差を「定位が良い／悪い」と一律には解釈せず、ブラインド試聴で中心像と残響幅を確認する。

## 人工信号と対照実験

Phase 32で生成した一定周波数の437.3 Hz正弦波、110 Hz＋倍音、指数減衰白色ノイズ、白色／ピンク色短バースト、クリック列の[結果](../phase32/metrics.csv)を再参照した。Phase 31 Bの437.3 Hz主周波数は**437.297 Hz**、中央部のRMS幅0.047 dB。倍音音は約110.000 Hz、RMS幅0.218 dBで、一定の楽音では音程と包絡は安定する。B1は倍音音の包絡幅が**6.005 dB**となり、単純な位相ロック停止はむしろ周期的な変動を作る。白色／ピンク色バーストでは位置・前20 msエネルギー・幅が方式ごとに変化し、単一の最大ピークは過渡音の正確な位置を表さない。

新たに、再現可能な固定乱数種の**指数減衰ピンクノイズ**と**単発ドラム風アタック＋減衰ノイズ**を0.25倍速で作成した。[入力・出力ハッシュ](synthetic_manifest.csv)、[指標](synthetic_diagnostics.csv)。ピンクノイズの入力減衰傾斜は出力時間軸換算で**−6.20 dB/s**、B出力は**−6.63 dB/s**、入力に対する余韻包絡誤差は**1.32 dB**、相関0.902。B1は**1.58 dB／0.861**に悪化。B3は包絡誤差1.22 dBでも、単発ドラムのピークが約63 ms遅れ、強度も低下した。数値だけでは採用しない。追加人工信号の計測付きレンダリングも従来研究レンダリングとバイト一致した。

低速Bの窓重ね条件はPhase 31/32の値を維持し、最大合成ホップはLow/Mid/Highで**6144/3072/768**サンプル（各窓長の0.75倍）、最悪の内部Hann²重みは**0.0686以上**。窓の欠落・NaN/Infは観測されていない。これは正常な音色を保証するものではなく、OLAの単純な空白が水っぽさの主因という説明を退けるための安全性確認である。

## 原因仮説の整理

| 仮説 | 今回の結果 |
|---|---|
| 試聴ファイルの取り違え | rawと試聴用の全SHA照合で否定。ユーザーがどのB方式をより悪いと感じたかまでは未確認 |
| 単純なOLA窓の欠落 | Bのホップ・正規化重みと全音声の有限性から支持されない |
| クロスオーバーだけで揺れが生じる | 生Low/Mid/Highに既に帯域包絡変動があり、FIR前後で誤差が大きく増えない。単独原因としては支持されない |
| 全bin位相リセットだけが余韻の原因 | B2でも余韻包絡は改善せず、Side/Midと実Drumsアタックが悪化。単独原因としては支持されない |
| 位相ロックの非ピークbin・所有領域変更が寄与 | フレーム位相残差は実測される。**寄与の可能性はあるが可聴性と因果関係は未証明**。B1全面OFFは逆効果 |
| ノイズ性余韻・複数音源を4倍へ引き延ばす際の時間的な帯域包絡／位相関係の揺れ | 入力対応の余韻・MIX包絡誤差と解像度別位相差が支持する。ただし聴感上の支配要因は未特定 |

## ブラインド試聴

同一入力区間の**Drumsアタック、Drums余韻、MIX重畳部、MIX静穏部、Vocal母音**を、Phase 31 BとPhase 32 B1/B2/B3から方式名を隠して再配置した。各フォルダの`A.wav`〜`D.wav`を数回ランダムな順に聴き、各箇所で「水っぽさ、アタック、前響き、定位、音色の揺れ」を記録した後に[対応表](blind_key.csv)を開く。Vocalだけは元の比較が3方式なので3本。音声は既存のSHA検証済み試聴用WAVの**バイト同一コピー**であり、全方式共通ゲイン0.5、端点フェード3 msのみ。ブラインド音声は`results/phase33/blind/<区間>/`に保存されている。raw float32と試聴用ゲインは混同しない。

## 回帰、安全性、次の1〜2実験

ビルド・全CTest・25本Golden照合の結果は、このレポート末尾の検証記録へ記す。Phase 29/30の任意速度回帰は全CTestに含める。Phase 31 Bの14本とPhase 32の74本、計測付き再レンダリングの一致を維持した。0.25 Bは比較基準としてのみ保存し、0.50〜1.00倍速の正式処理へ新方式を入れない。

1. **まずブラインド試聴で可聴区間を確定する。** 特にDrums余韻とMIX重畳部について、どの方式のどの時間帯で水っぽさが悪化するか、単なるレベル差か定位差かをユーザーの反復評価で確認する。今回は「改善した」という判定を出さない。
2. **次に、ピーク所有領域の切替だけを局所的に観察する対照実験を検討する。** 余韻の短い同一区間で切替前後のMid/High生出力、FIR後寄与、位相と包絡を並べ、入力にも同様の変動があるか確かめる。音声変更を試す場合もピーク位相ロック全体やイベント保護は維持し、単一変更・同一ゲイン・アタック／ステレオの安全性を満たすまでは採用しない。
