# Phase 32 — 極低速の水っぽさの原因切り分け

## 判定

0.25倍速のPhase 31方式Bは**音質未合格のまま**。MIX全体とDrumsの余韻で水っぽさを感じるというユーザーの試聴結果を本研究の出発点とした。位相ロック停止、過渡音時の位相リセット停止、毎フレームの位相伝播停止を**それぞれ単独**で試したが、持続音・アタック・ステレオのいずれかに明確な副作用があり、採用できる改善候補は得られなかった。数値だけを理由に音質合格とはしない。

0.50〜1.00倍速の正式Experimental 3500、Phase 30の再生経路、Phase 12/28 Golden、Phase 31方式Bは変更していない。Phase 32は独立した研究用エンジンと測定だけである。

## 入力、方式、再現性

Phase 31と同一のMIX、Drums、Vocal、Bass、Guitar各10秒、6秒のクリック、8秒の437.3 Hz正弦波に加え、固定乱数種で生成した指数減衰ノイズ、ホワイト／ピンクノイズ短バースト、110 Hzと倍音の周期音を使用した。0.25／0.30倍速で計74本のraw float32 WAVを生成した。[全WAVの入力・出力ハッシュ、長さ、ピーク、時間、CPU、RSS](renders.csv)。個人音源とWAVはGit対象外の`results/phase32`へ置く。

| 方式 | 独立した変更 | 判定 |
|---|---|---|
| A: Phase 31 B | 8192/1024、4096/512、1024/128の解析窓／ホップ、既存TimeMap・イベント・位相ロック・リセット | 比較基準。Phase 31の0.25／0.30出力と7音源×2速度の14本が**バイト一致**。 |
| B1: 位相ロックOFF | AからPeak Phase LockingだけOFF。位相伝播、リセット、TimeMap、ステレオ処理は継続。 | 不採用。クリックの最小ピークは改善したが、周期音とMIXの音色変動が増加。 |
| B2: イベント位相リセットOFF | Aから過渡音フレームの全bin位相リセットだけOFF。イベントTimeMapと精密アンカーは維持。 | 不採用。DrumsのSide/Midが大きく変化し、アタック前の響きも増えた。 |
| B3: 毎フレーム位相再同期 | Aの位相伝播だけを毎フレームの入力位相合わせに置換。位相ロック・イベントTimeMapは維持。 | 不採用。周期音の位相安定性とDrumsの左右比が悪化。 |
| C: ノイズ余韻の専用位相処理 | B1/B3の成分診断を先行した。 | **未実装**。一律の位相変更では副作用が大きく、成分分類なしに追加しない。 |
| D: Phase 31 Cの可変解析距離DSP | 方式A/Bの原因診断を先行した。 | **未実装**。解析距離可変時の瞬時周波数・位相伝播・イベントリセットの定義が必要。 |

B1/B2/B3は同じ入力・TimeMap・合成ホップ・OLA・FIRを使う。処理中のLow/Mid/High位相、OLA信号・重み、LP250/LP3500 FIR履歴はリセットしない。過渡音保護幅と精密アンカーは変更していない。方式C/DのWAVは存在しない。

## 位相、OLA、過渡音の診断

位相ロックは水っぽさの単一原因ではない。0.25倍速の110 Hz倍音信号では、隣接フレーム間の倍音位相残差の標準偏差がAの約**0.0003 rad**からB1の**0.088 rad**へ増加し、重み付きスペクトル変動も**0.0083→0.377**となった。437.3 Hz正弦波でも変動が増加した。[全信号の測定](metrics.csv)。B3の倍音位相残差は**0.284 rad**で、位相伝播を単純にやめると持続音がさらに不安定になる。

0.25倍速の437.3 Hz正弦波の主周波数はA **437.297 Hz**、B1 **437.297 Hz**で音程自体は維持されたが、中央3秒の50 ms RMS包絡の5〜95パーセンタイル幅は**0.047→1.748 dB**へ増えた。110 Hz倍音信号でも主周波数は両方式約110.000 Hzなのに、包絡幅は**0.218→6.005 dB**。B1は音程を保っても音量・音色が周期的に揺れる。B3の110 Hz推定は**109.53 Hz**で、位相伝播停止の副作用を示す。

0.25倍速クリックの最小ピークはAの**0.371**からB1の**0.699**へ増え、最大位置誤差は**5.25→2.58 ms**へ減った。しかしB1の指数減衰ノイズでは、包絡を指数関数に近似した後の揺れが**0.357→0.503 dB**に増え、アタック最小ピークは**0.460→0.357**へ下がった。単独クリックの改善を、余韻の改善へ一般化できない。白色・ピンク色短バーストでもピーク、最初20 msエネルギー、前20 msエネルギーに方式依存の差がある。これらは[人工信号表](metrics.csv)に記録し、短いバーストの最大ピーク位置を「イベント検出位置」と混同しない。

クリックの平均半値幅はA **0.033 ms**、B1 **0.021 ms**、B2 **0.036 ms**。B2のクリック前20 ms平均パワーはAの**2.81×10⁻⁵**に対し**5.33×10⁻⁵**へ増えた。短い単一インパルスの指標であり、Drums全体の音質を代表しない。

B2の0.25倍速Drums全体のSide/MidはAの**0.222→0.605**、余韻区間では**0.260→0.584**。MIX全体でも**0.293→0.365**となった。リセット停止による定位変化が大きく、採用しない。B3のDrums余韻のRMSはAの**0.0742→0.0611**へ下がるため、余韻のエネルギー保存にも問題がある。

方式Aの0.25倍速でLow/Mid/Highの実測最大合成ホップは窓長の0.75倍以内で正。Phase 31の幾何測定で最悪内部Hann²重みは0.0686以上だった。方式B1/B2/B3は同じTimeMapと解析フレーム列なので、このOLA条件は不変。**窓の欠落が今回の水っぽさの直接原因とは考えにくい**が、窓重なりだけでは音質を保証できない。0.25〜0.30のTimeMap・過渡音イベント、リセット予定列は変更せず、設定による位相出力だけを比較した。

MIX全区間の0.25倍速では、AのLow/Mid/Highの実際の解析フレーム数はそれぞれ**1,943／3,881／15,509**、最大合成ホップは**6,144／3,072／768**サンプル。窓長8,192／4,096／1,024を超える区間は0。Phase 31の通常ホップに対して解析フレーム数は約2倍。0.30倍速の最大ホップは**5,120／2,560／640**サンプル。これは実測TimeMapの丸め、イベント補償を含む値である。[全フレーム・ホップ表](../phase31/metrics/mix.csv)。

## 帯域・成分別の比較

Low/Mid/Highの各解像度が合成した未クロスオーバー波形をMIXとDrumsについて別WAVで保存した。これは**各解像度の生出力**であり、最終音声内の帯域寄与と同一ではない。最終音声を250 Hz未満、250〜3500 Hz、3500 Hz以上に分けた周波数別の測定も別途行った。[解像度別データ](stems.csv)、[局所区間](regions.csv)、[周波数帯別データ](frequency_bands.csv)。

| 0.25倍速の区間 | 方式Aの値 | B1の値 | 解釈の限界 |
|---|---:|---:|---|
| Drums余韻・高域の隣接スペクトル変動 | 0.296 | 0.282 | 高域で変動はあるが、B1のほうが少し低いだけで余韻の自然さは証明できない。 |
| Drums余韻・中域の隣接スペクトル変動 | 0.220 | 0.252 | B1では中域が悪化。 |
| MIX楽器重畳部・高域の包絡標準偏差 | 7.10 dB | 6.84 dB | 演奏由来の変化も含むため「水っぽさ」の直接測定ではない。 |
| MIX楽器重畳部・中域の隣接スペクトル変動 | 0.193 | 0.242 | B1では中域が悪化。 |
| Drums余韻・生High解像度の位相変動 | 0.880 rad | 0.882 rad | 位相ロック停止だけではHigh経路の変動はほぼ変わらない。 |

Drumsのアタックを含む入力3.77〜4.02秒、余韻のみ4.05〜4.35秒を分けた。余韻のAのRMSは**0.0742**、B1は**0.0694**、B2は**0.0729**。余韻の合成音ではスペクトル変動がA **0.389**、B1 **0.415**、B2 **0.383**で、小さい数値差から聴感を断定しない。MIXの楽器重畳部2.9〜4.2秒、比較的静かな4.2〜4.8秒、Vocalの母音を含む3.2〜3.85秒も同じ位置から切り出した。Vocal母音区間の包絡標準偏差はA **5.68 dB**、B1 **6.48 dB**で、位相ロック停止は安定化を示さない。

**現時点の原因仮説**は、4倍伸張でノイズ性の余韻や複数楽器の時間変化を長く引き延ばす際、フレームごとの位相関係と3解像度の別々の合成結果が揺れること。OLA欠落と「位相ロックだけが原因」という説明は今回の比較結果に合わない。ただし、どの成分の位相関係が可聴の水っぽさを支配するかは特定できていない。High生出力の変動と最終高域の変動は診断上の手掛かりであり、因果関係の証明ではない。

人工指数減衰ノイズではAの減衰包絡からの揺れは0.25倍速**0.357 dB**、0.30倍速**0.350 dB**。B1はそれぞれ**0.503／0.457 dB**、B2は**0.363／0.358 dB**。Drums実音源では複数の楽器・残響が重なるため、この人工音ほど単純な指数減衰を仮定しない。

## 比較WAVと試聴手順

全方式のraw出力は`raw/`、試聴用の19短区間は`audition/`。試聴用だけ**全方式に同じ0.5ゲイン**を掛け、ファイルの切り出しによる端点クリックを防ぐため先頭・末尾だけ同じ3 msのフェードを施した。自動ラウドネス補正とピーク正規化は使っていない。試聴用最大ピークは**0.813未満**。raw DSPの測定・比較にはこの処理を混ぜない。[試聴ファイル・SHA-256・入力位置](audition.csv)。

次の順で同一方式の複数回試聴を推奨する。

1. [Drums余韻A](audition/drums_tail_baseline_025_gain050.wav)と[余韻B1](audition/drums_tail_no_lock_025_gain050.wav)：余韻の水っぽさ、ザラつき、減衰と定位。
2. [DrumsアタックA](audition/drums_attack_baseline_025_gain050.wav)と[アタックB1](audition/drums_attack_no_lock_025_gain050.wav)：強度、二重化、前響き。B2も[別ファイル](audition/drums_attack_no_reset_025_gain050.wav)で定位を確認。
3. [MIX重畳部A](audition/mix_busy_baseline_025_gain050.wav)、[B1](audition/mix_busy_no_lock_025_gain050.wav)、[B2](audition/mix_busy_no_reset_025_gain050.wav)：音色の揺れと定位。
4. [MIX静かな部位A](audition/mix_quiet_baseline_025_gain050.wav)と[静かな部位B1](audition/mix_quiet_no_lock_025_gain050.wav)：残響の動き。
5. [Vocal母音A](audition/vocal_vowel_baseline_025_gain050.wav)と[母音B1](audition/vocal_vowel_no_lock_025_gain050.wav)：母音の芯と揺れ。

方式名を示さないブラインド試聴を行う場合は、[一覧](audition.csv)からファイルをコピーしてランダムな名称にし、対応表を別保管する。今回は主観評価をまだ得ていない。

## 性能、安全性、既存回帰

11音源の0.25倍速でAの処理実時間中央値は**1.79秒**、CPU user中央値**1.71秒**、最大RSS**17.14 MiB**。B1はそれぞれ**1.64秒／1.47秒／17.14 MiB**、B2は**1.78秒／1.70秒／16.28 MiB**。0.30倍速のA中央値は**1.77秒**。実音源10秒、人工音源6〜8秒の混合集計であり、速度帯の実機CPU期限を表さない。方式A/B1/B2/B3の解析ホップとフレーム数は同じで、Phase 31の半ホップに対する追加FFT負荷はない。[方式別全行](renders.csv)。

74本すべてでraw WAVの出力長が`round(inputFrames/speed)`と一致し、NaN/Infなし。rawの最大ピークはMIX・B1・0.25倍速の**1.8734**で、float WAVとして有効でも再生時のクリッピングには注意が必要。試聴用には固定ヘッドルームを用いた。別途0.49 Bと0.50 Aの境界4本を再生成した。[境界のハッシュと指標](boundary.csv)。MIXの0.50出力は[Phase 31 A](../phase31/REPORT.md)とバイト一致。クリックの最小ピークは0.49で**0.443**、0.50で**0.620**、位置誤差は**0.90／0.85 ms**。境界直前のアタック差が残る。境界を連続可変再生へ接続していない。

Phase 12/28 GoldenはMIX、Vocal、Bass、Drums、Guitarの0.50／0.60／0.70／0.75／0.80倍速、**25/25本がWAV全体でバイト一致**した。[Golden照合ログ](golden_regression.log)。実行器が測定時刻入りの`results/phase30/fixed.csv`を再生成するため、照合後にGit版へ戻して既存成果物の変更を残していない。

既存CTestの**40/40が成功**し、Phase 29/30の可変速度回帰も含む。[全回帰ログ](ctest.log)。追加したPhase 32専用テストは別途**1/1成功**し、0.25／0.30／0.50でPhase 31出力とのバイト一致、Low/Mid/High出力、位相設定変更の実効性、範囲外速度の拒否を確認した。[追加試験ログ](phase32_test.log)。フルビルドも成功。[ビルドログ](build.log)。既存Golden音声や正式DSPは更新していない。

## 2.00倍速と次段階

ユーザーの試聴では**2.00倍速は多少の妥協を感じるが許容範囲**。Phase 31で人工クリックのピークが入力0.8から出力0.149〜0.192へ下がった事実も維持する。単一人工信号の低下だけで2.00倍速全体を全面的に不合格とはしない。今回は高速側を改修していない。

次段階は、余韻のノイズ成分と楽音成分を分けて位相コヒーレンスを扱う独立試作を検討する。その前にA/B1/B2の同一ゲインAB試聴で、どの成分の水っぽさが実際に減るか確認する。Low/Mid/Highの生出力と最終帯域を混同せず、Drumsのアタックと余韻、MIXの重畳・静穏部を別々に判定する。高速側は別フェーズで、イベント間圧縮と精密アンカーを総出力長・過渡音保護・ステレオ整合を守って設計する。Phase 10.1の局所TimeMapと伸張債務返済は使用しない。
