# Phase 5.3 High / Phase 9C：長尺 MIX 0.50倍 比較

## 結論と試聴ファイル

- [Phase 5.3 High 試聴 WAV](phase53_matched.wav)
- [Phase 9C 試聴 WAV](phase9c_matched.wav)

**Phase 9C の左右独立処理は、定位指標を大きく変えた。** Side/Mid 比は Phase 5.3 が0.260、Phase 9C が0.586、左右相関は0.873対0.489。Phase 9C のモノラル試作エンジンを左右に適用した結果であり、Phase 9C をステレオ MIX に採用できる根拠にはならない。アタック、水っぽさ、音色の揺れ、シンバルの自然さは人間の試聴が未実施なので優劣を断定しない。Phase 11 の新規 DSP 実装は保留したまま。

## 入力と処理条件

入力は共有済み `/Users/taro252/Downloads/mix.wav`（44.1 kHz、ステレオ、16-bit PCM、約290.07秒）。**30.000秒から75.000秒の45.000秒**をサンプル位置 1,323,000〜3,307,499 として切り出し、両方式に同じ32-bit floatの入力を渡した。切り出し入力は1,984,500フレーム、期待出力は3,969,000フレーム。入力区間の SHA-256 は `6c21bfbf538883529c548e1c452d65ed525b42a466f3db348aaa8a6a252a551c`、元ファイルは `88beb7a0e5819a84f71e608b5250213a983f3c2f8638317e25bc739197fb3d79`。

- Phase 5.3：既存の `timestretch` を `--speed 0.5 --phase-locking on --transient on --adaptive-time-map on --precise-anchoring on --stereo-coherence on --quality high --chunked on` で実行。Low 8192/2048、Mid 4096/1024、LP250 の既定 High 構成。partial tracking、PVSOLA 等の実験機能は OFF。
- Phase 9C：既存の `tonal_residual_stretch --speed 0.5`。この CLI は**モノラル専用**で、ステレオの直接入力は拒否する。切り出し入力の L/R を無加工で分離し、各チャンネルを順番に同一設定の既存 Phase 9C へ通して再結合した。結合した各チャンネルと個別出力の最大サンプル差は0。Phase 9C の追跡・残差・合成アルゴリズムは変更していない。左右のトラックと残差位相は独立であり、ステレオ整合処理は**存在しない**。

45秒の長尺モノラル入力は処理できた。左は入力1,984,500→出力3,969,000フレーム、処理約6.84秒、右は同じ長さで約7.26秒。左の track birth/death は各9,137、右は各8,592、両方の中央値寿命は約58 ms。長さによるエラーは出ていない。ただし、内部に全長の複数バッファを持つオフライン方式であり、さらに長い曲でのメモリ上限は今回評価していない。

入力と伸長出力の振幅が異なるのは処理と音量一致によるものなので、RMS の大小だけで品質は判定しない。50 ms 窓の実効値には途中でゼロ近傍へ落ち込む区間がなく、連続ゼロも検出されなかった。これで目立つ無音欠落は否定できるが、短いクリック・音切れの不在までは保証しない。最終試聴コピーには非有限値や1を超えるサンプルはない。元の float WAV は両方とも1を超えるピークがあり、試聴コピーで共通条件のクリップ回避をした。

10秒ごとの Side/Mid 比は Phase 5.3 で概ね0.21〜0.30、Phase 9C で0.51〜0.63。Phase 9C の広がり増加は単一箇所の外れ値ではない。既存の `stereo_spectral_metrics` による入力との位相差 RMS は約37.7°対78.4°、音量差 RMS は約1.79対4.03 dB。ただし低域位相差は有効 bin が各窓1〜3程度で不安定なので、低域の数値だけで定位を判定しない。

6 kHz以上の帯域エネルギー比（80 Hz〜16 kHzに対する比）は、入力0.0448、Phase 5.3 が0.0349、Phase 9C が0.0383。これはシンバルを単独抽出した指標ではなく、高域の量の参考値。金属的な響きや減衰の自然さを表さない。

## 試聴の確認点と現時点の判断

1. **アタック**：キック／スネアの位置と幅、二重化、前響きを同じ箇所で交互に確認。
2. **水っぽさ・音色の揺れ**：中央ボーカルと持続音、残響で揺れや粒立ちを確認。Phase 9D で報告された「孤立ボーカルでは Phase 9C の水っぽさが少ない」というユーザーの評価が、長尺 MIX にも当てはまるとはまだ仮定しない。
3. **シンバル**：減衰、ざらつき、金属的なリンギングと前響きを確認。
4. **定位**：中央ボーカル・キック・ベースのセンター、左右の広がり、モノラルに畳んだ際の位相感を重点確認。Phase 9C の左右独立処理には大きな指標悪化がある。
5. **時間変化**：90秒を通して局所的な音量増大、短い欠落、拍の揺れを確認。客観測定だけでは可聴かどうかを決めない。

**人間による今回の MIX の A/B 試聴結果はまだ得ていない。** したがって Phase 5.3 と Phase 9C のアタック・水っぽさの主観的な勝敗は未判定。ただしステレオ定位の客観指標は Phase 9C の単純な左右独立適用に不利で、この経路をそのまま製品 MIX 処理へ採用しない。モノラルボーカル処理としての Phase 9C 評価とは分けて扱う。
