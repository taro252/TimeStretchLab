# Phase 5.2 — Multi-resolution Ablation Study

## 比較条件と構造

Phase 5.1 の逐次 WAV 処理に `--ablation a|b|c` を追加した。省略時は従来の C で、音質処理式や既定出力は変更しない。

| モード | STFT（FFT点数/入力ホップ） | 合成 |
|---|---|---|
| A | 中 4096/1024 | 中のみ。Phase 4 の単一解像度に相当 |
| B | 低 8192/2048、中 4096/1024 | `mid + LP250(low-mid)` |
| C | 低 8192/2048、中 4096/1024、高 1024/256 | `high + LP250(low-mid) + LP3500(mid-high)`。Phase 5.1 |

全モードで中経路の検出器、過渡イベント、精密アンカー、適応 TimeMap、位相ロック、ステレオ位相補正を共有する。B は高経路を生成せず、既存の 250 Hz・2049 タップ FIR を用いる。線形位相の係数、遅延中心、曲頭と曲末のゼロ境界処理は C と同一。処理済みサンプルは 16384 サンプルずつ float32 WAV へ書き込む。全モードでゲイン変更・正規化なし。

試験では A と既存の Phase 4 単一解像度処理の最大差 0、C とモード無指定の Phase 5.1 の最大差 0（人工ステレオ、両速度）。実音源でも Bass 0.50x の A 対 Phase 4、Mix 0.75x の C 対通常 Phase 5.1 は全サンプルが完全一致した。11件の全単体試験成功。24件の実音源比較で A/B/C の TimeMap ハッシュ、イベント数、出力サンプル数が組ごとに一致した。36件の人工信号比較でも TimeMap ハッシュと出力サンプル数が一致した。全 WAV は有限値のみ。人工信号の A/B/C 出力長は 0.75x で256000、0.50x で384000サンプル。実音源は同一の90〜135秒の45秒区間を切り出した。Bass、女性・男性 Vocal は48 kHzで出力2880000/4320000サンプル、Mixは44.1 kHzで2646000/3969000サンプル。すべて期待値と一致する。

## 人工信号

入力は [生成・計測スクリプト](../../scripts/phase52_artificial.py)、全値は [人工信号 CSV](artificial/metrics.csv)。純音の主周波数は A/B/C で同等。55 Hz の周波数変動（セント単位の標準偏差）は 0.75x で A 10.25、B/C 9.94、0.50x で A 23.52、B/C 23.20。82.41 Hz と110 Hz では全構成の変動がほぼゼロで、低経路の明確な追加効果は見られなかった。55 Hz の振幅変動係数はむしろ A 0.0518→B 0.0558（0.75x）、A 0.0937→B 0.0970（0.50x）と微増した。したがって純音だけでは B の一律な優位は示せない。

110 Hz＋第2〜5倍音の Bass では、0.75x の主音周波数変動は A 0.000126→B/C 0.000077セント、振幅変動係数は A 2.92×10⁻⁶→B/C 1.24×10⁻⁶。0.50x では A のほうがこの2指標で小さいが、いずれも微小値である。第2〜5倍音の相対レベルは最大0.016 dB程度の差で、C の追加改善はない。

短いノイズバーストは入力0.5秒に置いた。ピーク位置誤差は A/B/C 共通で0.75x −9.98 ms、0.50x −25.00 ms。高経路は前進を修正しなかった。以下は同じゲイン、理想出力位置からの最初の20 msのエネルギー。`pre-echo` は検出された10%立上りの直前20 msのエネルギーであり、無音の先行漏れを測る代理指標である。

| 速度 | モード | 10→90%立上り ms | ピークまで ms | 最初20 msのエネルギー | pre-echo エネルギー | −3 dB/−10 dB減衰 ms |
|---|---|---:|---:|---:|---:|---:|
| 0.75 | B | 0.313 | 0.479 | 0.005163 | 0.02537 | 0.271 / 1.375 |
| 0.75 | C | 0.313 | 0.479 | 0.000455 | 0.04531 | 0.271 / 1.354 |
| 0.50 | B | 6.750 | 15.000 | 0.000743 | 0.000504 | 0.667 / 3.771 |
| 0.50 | C | 5.313 | 15.000 | 0.000061 | 0.000164 | 0.458 / 3.396 |

C の最初20 msエネルギーは B 比で0.75x約91.2%、0.50x約91.8%減少した。理想位置より前へピークが移るため、理想位置基準の指標とピーク基準の指標を併記する必要がある。0.75x の C は pre-echo 代理指標も増えた。0.50x の減少だけを音質改善とは解釈できない。

高域成分を残した減衰ノイズ（シンバル状）の B→C 比較：

| 速度 | 構成 | ピーク位置誤差 ms | 最初20 msエネルギー | pre-echo エネルギー | −10 dB減衰 ms | 減衰包絡変動 dB |
|---|---|---:|---:|---:|---:|---:|
| 0.75 | B | −0.729 | 13.785 | 0.000938 | 43.10 | 0.353 |
| 0.75 | C | −0.729 | 12.505 | 0.003107 | 48.50 | 0.364 |
| 0.50 | B | −21.167 | 10.447 | 0.006199 | 46.44 | 0.402 |
| 0.50 | C | −22.313 | 11.093 | 0.015576 | 79.88 | 0.344 |

C は0.50xで減衰末尾が約33.4 ms延び、pre-echo代理指標は約2.5倍となった。高域スペクトルのピーク対平均比は B 11.24 dB→C 11.58 dB（0.50x）。金属的な響きの有無はこの数値だけで断定せず、試聴確認が必要。

## 実音源の客観指標

24出力の [実音源 CSV](real/metrics.csv) に Side/Mid、L/R相関、全帯域・150 Hz以下の入力対出力 IPD RMS（チャンネル間位相差）、ILD RMS（チャンネル間音量差）、RMS、ピーク、高域比率・高域立上り代理値、CPU時間、最大RSSを記録した。IPD/ILD は検出された有調波ビンに依存し、特に Vocal の低域 IPD は対象ビンが少ないため不安定になり得る。

Bass のピッチ指標：

| 速度 | 構成 | 中央周波数 Hz | 隣接フレーム変動中央値 cents | 90%値 cents |
|---|---|---:|---:|---:|
| 0.75 | A | 56.430 | 4.714 | 72.036 |
| 0.75 | B | 57.187 | 4.347 | 59.824 |
| 0.75 | C | 57.187 | 4.347 | 59.824 |
| 0.50 | A | 58.276 | 5.208 | 65.215 |
| 0.50 | B | 57.689 | 4.065 | 63.968 |
| 0.50 | C | 57.689 | 4.065 | 63.968 |

90〜135秒の Bass 区間では B が A よりピッチのフレーム間変動を抑え、C は追加改善なし。基音の正確な楽譜周波数は入力から指定していないため、中央周波数の大小自体をピッチ精度とは扱わない。

ステレオの主要値（0.50x、全24条件は CSV）：

| Mix | A/B/C | 0.2773/0.2728/0.2718 | 0.8572/0.8615/0.8624 | 29.520/29.790/30.826 | 12.264/8.931/8.931 | 2.467/2.470/2.612 |

0.75x でも Bass の Side/Mid は A/B/C 0.1066/0.1078/0.1078、Mix は0.2251/0.2262/0.2262で、大きなステレオ崩れは見られない。Mix の全帯域 IPD RMS は B→C で0.75x 13.03→13.89°、0.50x 29.79→30.83°と増えた。0.50x 男性 Vocal の低域 IPD RMS は A 17.34°に対し B/C 92.02°であり、低経路の採用判断に残る注意点である。低域の対象ビン数と音源内容を追加確認するまでは、この値をそのまま可聴な像崩れと断定しない。

Vocal の中高域代理指標（3.5〜12 kHzエネルギー比率 / 正の高域包絡変化の95%値）：女性0.75x は B 3.521% / 5.577 → C 3.873% / 4.878、女性0.50x は B 3.373% / 4.944 → C 3.872% / 3.786。男性0.75x は B 1.328% / 1.336 → C 1.370% / 1.184、男性0.50x は B 1.232% / 1.171 → C 1.318% / 0.967。C は高域比率を上げる一方、立上り代理値を下げた。これだけで子音明瞭度や水っぽさ、フォルマントのぼけは判定できない。中央像は上記 Side/Mid・相関・IPDを代理指標としている。

Mix の高域比率は B→C で0.75x 8.564→8.684%、0.50x 7.659→7.844%。キック、スネア、ハイハット、ピック、残響幅の個別ラベルを付けていないため、各楽器の聴感評価は後述の試聴課題とする。

## CPU・メモリ

4音源×2速度の各構成8件平均。音源と区間は同一、同時に最大3プロセス走らせた。CPU秒はプロセスの user＋system 時間、処理秒は壁時計時間。最大RSSは各プロセスの値。

| 構成 | CPU秒平均 | 処理秒平均 | 最大RSS平均 MiB | RSS範囲 MiB |
|---|---:|---:|---:|---:|
| A | 2.525 | 2.609 | 9.43 | 9.41〜9.48 |
| B | 4.863 | 4.998 | 13.94 | 13.91〜14.03 |
| C | 7.195 | 7.385 | 16.39 | 16.34〜16.42 |

B は C より CPU時間が約32.4%短い。C は B より約47.9%多い CPU時間を要した。入力45秒に対する測定で、出力 WAV のディスク書込時間を含む。全経路で Phase 5.1 の低メモリ逐次処理を維持した。

## AB試聴で確認する点と判断

比較 WAV は `real/{bass,mix,female,male}_{075,050}_{a,b,c}.wav`。同じ45秒区間・ゲイン・サンプル形式なのでレベル調整なしで切り替えられる。Bass は A/B で低音の揺れ、B/C で不要なざらつき。女性・男性 Vocal は子音・歯擦音、水っぽさ、母音の輪郭、中央像。Mix はキック、スネア、ハイハット、シンバル、ギターのピック、中央 Vocal、残響幅を重点的に聴く。主観試聴はこの実装検証では未実施であり、明瞭さや金属音の優劣を客観値だけから確定しない。

**低経路：採用候補として維持。** 実 Bass の両速度で隣接ピッチ変動が改善し、人工55 Hzでも周波数変動がわずかに減った。一方、純音の振幅変動と男性 Vocal 0.50x の低域 IPD 指標には留意する。

**1024点高経路：現時点では採用を推奨しない。** Bass ピッチ改善はなく、短いバーストの最初20 msエネルギーが約91%減り、シンバル状信号の先行漏れと減衰尾が増えた。CPU費用に対して子音・シンバル・ピックの明確な改善を客観測定では確認できない。比較実験の結論としては B を優先する。ただし Phase 5.1 の回帰条件に従い、通常の既定出力は C のまま保持し、B は明示的な比較モードで選ぶ。

Pitch Shift、Swift、リアルタイム再生、追加のDSP機能は実装していない。D（高2048）は今回比較しなかった。
