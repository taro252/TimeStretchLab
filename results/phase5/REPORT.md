# Phase 5 — 複数解像度タイムストレッチ検証

## 実装構成

`--multiresolution on` で低域8192点/解析ホップ2048、中域4096点/1024、高域1024点/256の3経路を使用する。サンプルレート44.1/48 kHzに対応する。中域はPhase 4と同じ設定で先に処理し、イベント検出・統合、適応的時間配置、精密アンカーを一度だけ決定する。`TimeMap::outputPositionForInputSample()` が中域フレーム間の合成開始時刻を補間し、低域・高域の各フレームが**同じ入力サンプル時刻から出力位置を得る**。過渡イベントとリセット対象時刻も中域から共有する。各経路の位相ボコーダー、ピーク位相固定、Phase 4ステレオ位相補正は独立した状態で動くが、設定方針は同一。Phase 3.6の選択的リセットは使わない。

3つの時間領域出力を、中心を合わせた対称Blackman窓FIRのFFT畳み込みで合成する。`output = high + LP250(low−mid) + LP3500(mid−high)`。従って周波数重みは低域 `LP250`、中域 `LP3500−LP250`、高域 `1−LP3500` で、和は常に1。低/中の重なりは概ね200〜300 Hz、中/高は概ね3000〜4000 Hz。FIRは零位相に配置し、経路間に群遅延差を追加しない。単純なIIRクロスオーバーは使わない。FFTの設定とブロック作業領域は再利用し、音声フレーム内では可変長メモリを確保しない。

重みの実測例（44.1 kHz）：低100 Hz **0.99995**、低350 Hz **0.00004**、中1000 Hz **1.00000**、中4500 Hz **0.00000**、高2500 Hz **0.00000**、高5000 Hz **1.00000**。同じ入力を3経路に与えた場合の合成誤差は0。`--multiresolution off` が既定で、通常品質としてPhase 4を保持する構造になっている。プリセットUIは追加していない。

## ビルド・回帰

Releaseビルド成功。CTestはPhase 1〜5の**9/9成功**。Phase 5 OFFのMix/Bass、0.75x/0.50xの全長4出力は、保存済みPhase 4と**最大サンプル差0、変更サンプル0**。[比較ログ](off_regression/comparison.txt)。Phase 5 ONのモノラル・ステレオ人工音、全長Mix/Bass、男女ボーカルにNaN/Infなし。全長4出力のサンプル数は期待値どおり。クリックの過渡イベント数・精密アンカー数・アンカー誤差はPhase 4と同じで、孤立クリックのアンカーは保持した。120 BPMクリック列では両速度とも8イベントをアンカーし、最大間隔誤差は0.75xで0.408 ms、0.50xで0.567 ms（目標3 ms以下）。

## 人工信号

[全測定値](artificial/metrics.txt)に55、82.41、110 Hzの0.75x/0.50x/0.40x、110 Hz+高調波、クリック、短いノイズバースト、減衰する高域ノイズ、ステレオ振幅差を記録した。純音の平均周波数誤差は全件1 Hz未満。FFTによる周波数推定値には窓長由来の一定偏りがあるため、標準偏差を揺れの比較に使う。

| 0.50x純音 | 周波数標準偏差 Phase 4→5 | 振幅標準偏差 Phase 4→5 |
| --- | ---: | ---: |
| 55 Hz | 0.000005→0.000016 Hz | 0.000019→0.000033 dB |
| 82.41 Hz | 0.000075→**0.000009** Hz | 0.000110→**0.000015** dB |
| 110 Hz | 0.000032→**0.000006** Hz | 0.000015→**0.000003** dB |
| 110 Hz+高調波 | 0.403→0.439 Hz | 0.516→0.600 dB |

55 HzのPhase 4はすでにほぼ無変動で、Phase 5に数値上の改善はない。高調波信号では0.50xの変動がやや増えた。0.40xでは3純音の周波数・振幅標準偏差がすべて低下した。

過渡指標は0.5 msの移動実効値包絡から計算した。立ち上がりはピークの10%→90%、ピーク到達時間は10%位置→ピーク。減衰時間はピークから−3/−10 dB、プレエコーは理想イベント位置の前20 msのエネルギー。20 msエネルギーは理想位置から後20 ms。クリックの立ち上がりは両方式とも測定分解能で0 ms。0.50xクリックのピーク位置差は0サンプル、0.75xは−5サンプル（Phase 5が早い）。

0.50x短いノイズバーストでは10%の立ち上がり開始位置は両方式で同じ（理想位置より25.24 ms早い）。10→90%立ち上がりは**19.68→7.78 ms**、10%位置からピークまでは**19.93→8.10 ms**。ピーク位置はPhase 5で522サンプル（11.84 ms）早く、プレエコーエネルギーは64.95→64.20、理想位置後20 msのエネルギーは0.705→0.219。短いランダムバーストでは、強いサンプルの選択が方式ごとに変わるためピーク単独ではアタックを代表しないが、**ピーク移動と初期20 msエネルギー低下は残る懸念**。

減衰する高域ノイズでは、0.50xの10→90%立ち上がり1.043→1.020 ms、ピーク位置差0、プレエコー10.69→10.28、−10 dB減衰28.10→28.19 ms。大きなアタック悪化は見られないが、明確な改善も小さい。金属的な響きや粒状の揺れは聴感で確認が必要。

全長約290秒の入力を0.75x/0.50xで処理した。Phase 4とPhase 5は同一ゲイン、同一区間の[AB試聴用WAV](real/audition/)を作成した。[一覧](real/manifest.csv)。Bass入力のSide/Midは0.1047、左右相関0.9975。Mix入力は0.2241、0.9044。

ステレオの幅・相関はPhase 4に近い。一方、IPD/ILDの重み付き誤差には小さな悪化もある。低域40〜150 HzのIPD誤差はBass 0.50xで2.11→1.66°、Mix 0.50xで15.84→13.28°に低下。指標は1秒ごとの対応位置に4096点FFTを掛け、強い入力ピークを左右の小さい方の振幅で重み付けしたRMS。適応的時間配置による局所位置差は補正していない。[全ステレオ指標](real/stereo_metrics.txt)、[IPD/ILD指標](real/spectral_metrics.txt)。

Bass 0.50xの音高変動は、隣接する安定フレーム間の変化中央値が**4.249→3.604 cents**、90パーセンタイルが**57.234→54.214 cents**。音高中央値は62.083→62.047 Hz。0.75xも変化中央値4.513→4.273 cents、90パーセンタイル59.248→58.864 cents。[音高指標](real/pitch_metrics.txt)。音高の変化には実際の演奏も含まれるため、これだけで周期的な揺れの完全解消とは判定しない。

## 男女ボーカルと資源使用量

共有された女性ボーカル `vocal.wav`、男性ボーカル `vocal-male.wav` の各60〜90秒区間を使用。[女性の結果](vocal/stereo_metrics.txt)、[男性の結果](vocal_male/stereo_metrics.txt)、各[女性AB](vocal/)・[男性AB](vocal_male/)を参照。女性0.50xのSide/Midは0.2755→0.2639、相関0.8590→0.8699。男性0.50xは0.1418→0.1430、相関0.9608→0.9602。中央像の指標に大きな後退はない。子音の明瞭さ、母音の水っぽさ、フォルマントのにじみは試聴で確認する必要がある。

全長処理時間はMixがPhase 5で40.55/45.33秒（0.75x/0.50x）、Bassが35.70/47.26秒。Phase 4の以前の記録はMix14.20/13.42秒、Bass11.97/12.34秒で、別実行の参考値。Bass 0.50xを再処理した際の最大常駐メモリは**1,345,814,528 bytes（約1,283.5 MiB）**。FIR畳み込みの再利用作業配列は81,944 bytesで、常駐メモリには入力、3出力、合成出力、重ね合わせ用配列などが含まれる。[処理時間](real/processing_metrics.txt)、[メモリ測定](real/memory_metrics.txt)。

## AB試聴と残る課題

Bassの持続音の周期的揺れ、キック低域、Mixのボーカル・スネア・シンバル・ギターのアタック、残響の広がりを同一ゲインで聴き比べる。男女ボーカルは子音、母音の濁り、中央像を比較する。**聴感による判定はまだ行っていない**。人工ノイズのピーク移動と初期20 msエネルギー低下、高調波信号の変動増加、MixのIPD/ILD誤差増加は残る。FIRの境界では入力外側を零として扱うため、音源の開始・終了付近にも注意が必要。全長浮動小数点WAVは一部ピークが1.0を超えるため、整数PCM化には別途ゲイン管理が必要。試聴用WAVは一律0.4倍で、ピーク1.0未満・有限値を確認した。

Pitch Shift、リアルタイム処理、Swift連携には進んでいない。
