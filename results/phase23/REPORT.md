# Phase 23 — 可変速度DSP音声の独立試作

## 結論と判定範囲

Phase 21の速度非依存解析とPhase 22BのA50 TimeMapを使い、0.50→0.75倍速のステレオfloat WAVを**正式再生経路と分離したC++試作**で生成した。MIX、Vocal、Bass、Drums、Guitar、人工クリック、437.3 Hz正弦波を処理した。固定0.50／0.75倍速では、実音源10本すべての試作WAVがPhase 12 Goldenと**バイト一致**した。人工2音源の固定速度4本もPhase 13の固定速度出力とバイト一致した。可変速度7本すべてで、要求時に確定済みとした出力サンプルは固定0.50 Goldenとビット単位で一致した。

**音質合格は保留**する。合成された速度変更音声のアタック、水っぽさ、母音の揺れ、定位は、以下の数値試験だけでは判断できない。特にMIX／Vocal／Drumsの[同一ゲイン試聴WAV](audition)を人間がA/B/C比較する必要がある。正式macOS再生、FIFO、シーク、連続速度変更、Phase 10.1処理には接続していない。

## 独立DSPの構造

`Phase23VariableSpeedEngine` はPhase 13のExperimental 3500合成順を独立した試作ファイルへ複製し、確定済みの共通 `TimeMap` を1本渡す。入力解析は既存 `Phase13StreamingEngine::analyzeTransientEvents` の結果を再利用する。過渡音リセット列は同じイベント列から構築し、速度を切り替える地点でもLow 8192/2048、Mid 4096/1024、High 1024/256それぞれのPhase Vocoder、ピーク位相ロック、ステレオ整合、OLAリングを再生成・リセットしない。LP250（2,049タップ）とLP3500（513タップ）の2系統FIRも、履歴と4,096点畳み込みブロック境界を維持する。位相やFIRの演算順はPhase 13と同一で、固定Golden一致によって確認した。

速度変更時のサンプル長は、可変TimeMapへ入力終端位置を投影して四捨五入した値。OLAとFIRはこの長さまで順次排出し、WAV writerが指定サンプル数を確認する。出力を全長保持するDSPバッファは作らない。試作の出力チャンクは16,384フレーム。OLAリング合計106,496サンプル、FIRリング合計65,536サンプル。WAV読み書き・解析・診断CSV出力は独立オフライン試作側で行う。

### 確定済み音声の保護

A50計画へ渡す公開境界には、要求時の固定0.50出力位置から**8,192出力サンプル先**を用いた。Lowの合成窓が過去へ及ぶ4,096サンプルとLP250の中心1,024サンプルなど、非因果の先読みが確定済みPCMを変更しないようにする保守的な余裕である。全7音源で要求時の座標までraw PCMの一致を実測した。ただし8,192の十分性を任意の曲・任意の切替位置に対して数学的に証明したものではなく、正式ワーカー接続前の境界試験が必要である。余裕は適用遅延にも加算される。

## 段別診断

切替近傍の同じ**入力フレーム番号**で固定0.50と可変出力の累積ハッシュを比較した。7音源・Low/Mid/Highの全21組でFFTハッシュは一致した。位相とIFFTはTimeMapの合成位置が変わったフレーム以降に差が生じ、それ以前は一致した。OLAの累積ハッシュは通常同じフレームから変わり、クリックでは窓の先読みのため位相差より数フレーム前から変わる。LP250/LP3500と最終出力のFIR累積ハッシュも切替後から変わる。各方式を**1回のDSP処理の中で**通しており、切替位置で状態を再構築していない。

最初に異なるフレーム番号とFIR出力サンプルは[stage_comparison.csv](stage_comparison.csv)、[fir_comparison.csv](fir_comparison.csv)に保存した。各フレームの実ハッシュは[diagnostics](diagnostics)内の `*.stages.csv`。例えばMIXでは位相の最初の差分はLow 493／Mid 985／High 3937フレーム、LP3500側FIRと最終出力の最初の差分は2,010,112出力サンプルだった。固定速度のFFT・位相・IFFT・OLA・FIRを含む最終WAVのバイト一致を別途確認した。

## 音声・アタック・定位の客観確認

- **無音・数値異常：** 可変7本すべてでNaN/Infなし。切替±100 msの10 ms窓に、周囲に信号があるのに突然ゼロになる箇所は0。raw最大ピークは0.256〜1.413。1.0を超えるピークは既存Goldenにもあり、DSP出力を変更せず試聴用だけ共通ゲイン0.5を掛けた。
- **切替境界：** 境界1サンプル微分は各音源の近傍微分99パーセンタイル以下。これは顕著な単発クリックがないことの数値的目安であり、聴感の代わりではない。MIXは0.0455対0.0724、Vocalは0.0105対0.0245、正弦波は0.0105対0.0114。
- **精密アタック：** 人工クリック12個を検出。通常の中央切替では先頭6個の位置・ピークが固定0.50と一致し、後半6個は固定0.75に対し**全て同じ100,727サンプルの時間移動**で揃った。ピーク差の最大は約5.96e-8、各アタックの半値幅はどれも1サンプル。クリック直上への追加要求では先頭7個が固定0.50と一致し、以後5個は固定0.75から一定の107,895サンプル移動。Drumsのイベント直上要求では保護された強いアタックがGoldenと同じ出力位置466,909、ピーク0.958032、半値幅115サンプルだった。これらは測定対象のアタックに限る。
- **音程・位相：** 437.3 Hz正弦波の切替前／後の主周波数は437.285216／437.285215 Hz。左右の位相差の実効値は前後とも0.785 rad、L/R相関0.707、Side/Mid比0.414で維持。持続音の切替後に顕著な音程変化を検出しなかった。
- **実音源の左右関係：** BassのL/R相関は前後0.997／0.997、Side/Mid比0.111／0.108、位相差実効値0.069／0.078 rad。MIXは相関0.876／0.847、Side/Mid 0.257／0.293。前後で入力内容が異なるため、他の実音源の左右指標の変動だけで定位劣化は判定しない。各音源のIPD（左右位相差）・ILD（左右レベル差）・スペクトル変動は[audio_metrics.csv](audio_metrics.csv)に記録した。
- **Vocalの音色：** 隣接短時間スペクトルの対数振幅差の中央値は切替前0.849、後0.820。これだけでは母音の水っぽさ、倍音変動、声の自然さを判定できない。試聴を優先する。

クリックの個別時刻・ピーク・幅は[click_attacks.csv](click_attacks.csv)、追加のアタック直上条件は[near_attack.csv](near_attack.csv)。

## 処理時間・メモリ・試聴ファイル

試作DSPの実測時間はMIX 6.83秒、Vocal 7.02秒、Bass 5.84秒、Drums 1.57秒、Guitar 1.46秒（各可変速度1回、解析時間は別でMIX 0.13秒前後）。プロセス最大常駐メモリは16.7〜17.1 MiB程度。時刻診断CSVの書き込みを含むMacオフライン計測であり、実機オーディオコールバックの期限保証ではない。全条件は[run_summary.csv](run_summary.csv)に記録した。

試聴WAVは[音源別auditionディレクトリ](audition)の `A_fixed_050.wav`、`B_fixed_075.wav`、`C_switch.wav`。MIX／Vocal／Bass／Drums／Guitarに加え人工クリックと正弦波もある。Drumsとクリックには `C_switch_on.wav` を追加した。**3方式とも同じ固定ゲイン0.5**で、全試聴WAVのピークは1.0未満。音量を曲ごと・方式ごとに自動調整していないため、A/B/Cの同一ゲイン比較ができる。raw DSP出力は[raw](raw)、元のGoldenはPhase 12に保存し、試聴用のゲインはどちらにも焼き込んでいない。試聴WAVの元ファイル・ゲイン・ピーク・SHA-256は[audition_manifest.csv](audition_manifest.csv)に記録した。

試聴では切替点の約0.5秒前から、クリック、キック・スネアの二重化、母音の揺れ／水っぽさ、シンバルの前響き、ボーカル中心定位、左右の広がりをA/B/Cで比較する。今回はCを音質合格と判断しない。

## 再現と残る課題

`cmake -S . -B build && cmake --build build --target phase13_stream phase23_audio` の後、`python3 tests/Phase23Study.py /Users/taro252/Docker/TimeStretchLab` でWAVとGolden照合を再実行できる。指標と試聴WAVはNumPyを使う `tests/Phase23Metrics.py`、`tests/Phase23Audition.py` で再生成する。`phase23_audio` は入力WAV、出力WAV、`050|075|switch`、診断CSV、切替要求入力サンプル（switchのみ）、任意の出力ブロック数を受け取る。時間写像とDSPの行単位診断は `results/phase23/diagnostics/` に保存した。

全体ビルド成功。`ctest --test-dir build --output-on-failure -j4` は**31/31成功**（116.33秒）。新規 `phase23` テストは固定0.50／0.75のPhase 13出力とのバイト一致、確定済みPCMの一致、8,192／16,384フレーム出力分割での可変WAVバイト一致、NaN/Infなしを確認した。実音源を含む14/14固定WAV照合と7本の可変WAV生成は上記研究スクリプトで別に実行した。

残る検証は、人間によるA/B/C試聴、任意位置での8,192サンプル確定余裕の境界証明、連続要求、FIFOを伴う公開領域、速度変更後の長尺実再生、時間写像以外の非因果処理が要求応答へ及ぼす影響である。A50の約0.19〜0.67秒の適用遅延も製品として未評価。過渡音保護幅の緩和やPhase 10.1の処理は今回実装していない。
