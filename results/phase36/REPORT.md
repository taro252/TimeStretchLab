# Phase 3.6 検証結果

## 実装

`--transient on --adaptive-time-map on --selective-reset on` でのみ有効です。Phase 3.5 のイベントを使い、ピークから最大 4 フレーム戻って spectral flux が閾値以下、またはピークの 25% 未満になる直後を `onsetFrame` とします。ピーク後は最大 6 フレーム見て、flux がピークの 20% 未満、対数エネルギーが局所最大の 10% 未満、かつエネルギーが増加していない時点の直前を `attackEndFrame` とします。人工ドラムではピーク 42、終了 45、単独インパルスではピーク 42、終了 44 になりました。

時間配置は開始前 2 フレームと終了後 10 フレームに raised cosine の滑らかな遷移を置き、開始から終了までは局所時間比 1.0 とします。イベント間の持続区間で長さを補償し、全体の出力サンプル数を保ちます。疎なクリックでは、イベント周囲の入力サンプルの最大値を使います。局所ピークと平均振幅の比が 20 以上の場合だけ、フレーム内の入力位置 `offset` を求め、イベント基準位置を `(globalRatio − 1) × offset` サンプル補正します。実音源で常にクリックをサンプル単位で特定できるという保証はありません。

イベントのピークで、各 bin の上昇量 `rise = max(currentMagnitude − previousMagnitude, 0)` と相対上昇量 `rise/(currentMagnitude + 1e-7)` を計算します。位相リセット量は `eventStrength × relativeRise × lowFrequencyWeight` です。重みは 120 Hz 以下で 0.2、120～250 Hz で余弦曲線により 1.0 へ移り、250 Hz 以上で 1.0 です。通常伝播位相と解析位相の単位複素ベクトルを重み付きで合成し、その角度を出力位相にします。角度を直接線形補間しません。内部の合成位相を更新した後、Phase 2 の Peak Phase Locking を適用します。イベント時刻と時間配置は左右共有、各 bin の上昇量は各チャンネル固有です。

`event_map.csv` はフレーム、flux、閾値、イベント ID、局所時間比、合成位置を、`events.csv` は開始・ピーク・終了と理想／実際の基準位置差を記録します。

## ビルドと単体テスト

ビルド成功。CTest は Phase 1、Phase 1 検証、Phase 2、Phase 3、Phase 3.5、Phase 3.6 の **6/6 成功**です。Phase 3.6 OFF＝Phase 3.5、Phase 3.5 OFF＝Phase 3、Transient OFF＝Phase 2 の最大サンプル差は 0 でした。定常正弦波は 0 イベントで Phase 3.5 と同一出力でした。選択的リセットの単体テストでは、定常低域 bin の位相ずれは 0、高域で上昇した bin は解析位相へ引き寄せられました。

## 実音源：Mix と Bass

Mix と Bass の全長を 0.75x／0.50x で処理し、Phase 2・3.5・3.6 の同一区間を固定ゲイン 0.4 で [試聴用 WAV](real/audition/) に保存しました。各素材の元音源 60～90 秒に対応します。12 ファイルすべて NaN/Inf がなく、試聴用ピークは 1.0 未満です。全長ファイルの出力サンプル数は期待値どおりです。

| 素材 | イベント数 | 件数/秒 | 間隔 50 ms 未満 | 50～100 ms | 100～200 ms | 200 ms 以上 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Mix | 844 | 2.910 | 0 | 0 | 53 | 790 |
| Bass | 761 | 2.624 | 0 | 0 | 159 | 601 |

間隔欄は連続したイベント間の件数です。両素材ともイベント基準位置の最大誤差は 0 サンプルでした。全長の [処理時間と件数](real/processing_metrics.txt) を参照してください。Mix は 0.75x／0.50x で 10.43／11.07 秒、Bass は 10.62／10.53 秒でした。

Mid は `(L+R)/2`、Side は `(L−R)/2`、Side/Mid は両者の実効値の比です。入力と処理後の左右関係を見るため、相関だけでなくこの比を使いました。数値全件は [ステレオ指標](real/stereo_metrics.txt) にあります。

Bass の 0.50x で Mid 実効値は入力 0.1214、Phase 2 0.0883、Phase 3.5 0.1170、Phase 3.6 0.0840 です。Side 実効値は順に 0.0127、0.0820、0.0177、0.0845 です。Phase 3.6 の Side が入力より大幅に大きく、左右の位相関係を保てていません。**ステレオ成功条件は未達**です。弱い低域再同期をイベント中に追加する試行も行いましたが、30 秒の Bass 抜粋で Side/Mid が約 0.63 にとどまり、人工ドラム幅も悪化したため採用していません。

Bass の低域優勢ピークを約 0.1 秒ごとに推定し、隣接する安定区間の音高差をセントで集計しました。[音高指標](real/bass_pitch_metrics.txt) では、0.50x の差の 90 パーセンタイルが Phase 2 56.7、Phase 3.5 56.8、Phase 3.6 51.0 セントです。音符の切替、倍音選択、ノイズを完全には除けないため、この指標だけで揺れや flutter がないとは判定できません。Bass のアタック明瞭度、低域の不連続も試聴で確認する必要があります。

## 判断と残る問題

Phase 3.6 はクリック時刻を改善しましたが、人工ドラム 0.50x の幅と実音源のステレオ幅を改善できていません。Phase 2 の独立した左右位相伝播が、低域の選択的リセットでは十分に同期しないことが主因と考えられます（測定結果からの推定）。Phase 3.5 の全 bin リセットは左右を近づけますが、Phase 3.6 の低域上限 0.2 ではその効果が弱まります。今回、高度なステレオ整合処理は追加していません。

Phase 3.6 は**実験的な任意機能**として既定では OFF のままにします。Mix の無補正ピークは 1.0 を超えます。クリックや roughness の聴感評価は数値測定からは確定できません。Multi-resolution、Advanced Stereo Coherence、Pitch Shift、Real-time Streaming、Swift integration には進んでいません。
