# Phase 38 — 高速アタック検証とノイズバーストの初動調査

2026-10-12。Phase 37方式Bの時間写像、イベント、位相処理、OLA、FIRおよび比較用raw PCMは変更していない。正式なExperimental 3500、Phase 30/36の再生経路、低速方式B、キャッシュ・シーク、Golden WAVも未変更。

## 結論

2.00倍速の白色・ピンク色ノイズバーストで、方式Bの「理想開始位置から固定20 ms」のエネルギーが極端に低かった主因は、**立ち上がりがTimeMap上で後ろへ移ったのに、測定窓を線形時刻のまま固定していたこと**。Bの実出力の立ち上がりは、実際の入力立ち上がりをBのTimeMapで変換した位置と、白色では平均 **0.21 ms**、ピンクでは **1.08 ms** 以内で一致した。Bの最大ピークとイベント全体のエネルギーはAより大きい。検証した3発のバーストでは、イベント全体が欠落した証拠はない。

ただし、立ち上がりを揃えた後でも最初の20 msのエネルギーはBが小さい。**白色 B/A = 0.53、ピンク B/A = 0.78**。Bの過渡音保護によって包絡が時間方向に広がるためで、これを単なる計測誤差として消してはならない。50 msのエネルギーと総エネルギーはBの方が大きい。今回は原因不明のゲイン補正や新しい位相処理を加えず、**方式Bを無修正で維持**する。短いノイズ系アタックの聴感評価が終わるまで正式採用を保留する。

## 精密診断の条件

Phase 32の48 kHz人工信号を再利用した。白色・ピンク色バーストは、0.6 / 2.5 / 4.4秒から120 msの対称Hann包絡で立ち上がるため、入力の公称開始サンプル自体はほぼ無音。入力の実際の立ち上がりを「局所1 ms RMS包絡が最大の10%を3 ms以上継続して超える最初の位置」として測った。白色の実立ち上がりは公称開始から平均13.17 ms、ピンクは17.46 ms後。出力でも同じ基準を使った。ステレオのエネルギーは左右の二乗値の平均で、左右差による相殺を避けた。

各バーストについて、(1)公称入力時刻÷速度、(2)実測入力立ち上がりをMid TimeMapで変換した位置、(3)実測出力立ち上がり、という3つの位置を分けた。各位置から5 / 10 / 20 / 50 msのエネルギーとRMSを測った。さらに前40～5 ms、後120～200 ms、理想位置の前50～後220 msの総エネルギーを保存した。[全36観測](burst_diagnostics.csv)、[イベントとアンカー](burst_events.csv)。

立ち上がり判定の閾値を5%と20%に振った対照でも、2.00倍速のBはAより遅い。白色の公称開始からの位置はAが3.51～10.12 ms、Bが21.42～32.06 ms、ピンクはAが−0.28～12.10 ms、Bが23.72～35.46 msで、特定の10%閾値だけに依存する結論ではない。

## イベント・TimeMap・実音源

白色・ピンク色・減衰白色ノイズの3イベントは、すべてサンプル単位アンカーの信頼度判定を満たさず、既存のフレームアンカーへフォールバックした。検出ピークは公称開始より約24 ms前の解析フレームにある。一方、鋭いクリックでは信頼度を満たすアンカーが使われる。したがって今回のバースト遅延を「精密アンカーの計算誤り」とは断定できない。Bはイベントピークを従来 `idealStartAt` へ固定し、保護区間と補償区間で局所比率を変える。イベントピークの位置誤差は0サンプル。イベントの検出結果やリセット列は変更していない。

実音源の5種類について、1.10 / 1.25 / 1.50 / 1.75 / 2.00倍速、A/Bの50条件を再測定した。MIX、Drums、Vocal、Guitar、Bassのイベント数はそれぞれ31 / 32 / 24 / 34 / 28（10秒、速度に依存しない）。**これらの実音源では信頼度を満たしたサンプル単位アンカーは0件**で、すべて従来フレームアンカーを使う。TimeMapイベントピークと理想位置の差は全条件0サンプル。[アンカー集計](real_anchors.csv)。

単純な線形時刻で比較した出力ピークのずれと、入力局所ピークを実際のTimeMapで写した位置でのずれを分離した。探索窓は入力±35 ms、出力TimeMap位置±40 msとし、複合楽器内の別ピークを選ぶ可能性があるため結果は**位置診断**であり楽器ごとの絶対的な正解時刻ではない。

|---|---:|---:|---:|---:|
| MIX | 7.5 ms | 12.0 ms | 6.2 ms | 0.769→0.902 |
| Drums | 5.8 ms | 14.8 ms | 5.1 ms | 0.624→0.814 |
| Vocal | 25.2 ms | 27.1 ms | 20.1 ms | 0.341→0.394 |

Phase 37で見えたMIX/Drumsの「位置ずれ悪化」の相当部分は、Bの非線形TimeMapを使わず線形時刻で測ったことによる。一方、Vocal/Guitarのピーク対応は重なりが多く、残るずれを音質上の無害な変動と断定しない。全1477イベント観測は[real_events.csv](real_events.csv)、速度別集計は[real_summary.csv](real_summary.csv)。

同一raw WAVの全体ステレオ指標も維持した。2.00倍速の Side/Mid・左右相関は、MIXがA `0.211 / 0.915`、B `0.195 / 0.927`、DrumsがA `0.166 / 0.956`、B `0.127 / 0.977`。VocalはA `0.186 / 0.934`、B `0.169 / 0.945`、GuitarはA `0.268 / 0.879`、B `0.270 / 0.878`、BassはA `0.105 / 0.997`、B `0.104 / 0.997`。Side/Mid は左右差の実効値を中央成分で割った値で、定位の一側面にすぎない。位相差を含む元データは[Phase 37の全指標](../phase37/metrics.csv)を参照する。方式BのDrumsは数値上やや中央寄りだが、Phase 37の試聴でユーザーは定位差を気にしなかった。

2.00倍速のBでは、MIX 31イベント中28区間、Drums 32イベント中29区間で保護強度が補償容量に制限された。下限局所比率は0.25、Mid合成ホップは256～1024サンプル。密集クリック（250 ms間隔）の24イベントでは容量制限16区間、危険なfallback0件。孤立バーストでは容量制限0件。どの区間も総出力フレーム数は厳密に維持した。[Phase 37レンダー一覧](../phase37/renders.csv)、[密集クリック試験](dense_renders.csv)。Low/Mid/Highの全396解像度条件でホップは正・窓長未満、Hann²重みの最小値は約1.5。[幾何検証](../phase37/geometry.csv)。

## 試聴セットと修正判断

Phase 37でユーザーが評価したMIX/DrumsのBのraw WAVをSHA-256で**132/132全件照合**し、変更しなかった。[監査](phase37_audit.csv)。Phase 38の[60本のブラインドWAV](audition/)は同じraw A/Bと密集クリックから生成し、MIX重畳／静穏、Drumsアタック／余韻、Vocal子音／母音、Guitarピック／持続、Bassアタック／持続、白色／ピンク色の単発ノイズ性アタック、MIX/Drums全体、密集クリックを含む。1.50 / 2.00倍速、全方式共通の固定ゲイン0.45。試聴WAVの最大ピークは0.626未満でクリッピングしない。切り出しは**同じ入力区間をそれぞれのTimeMapで出力座標へ写像**し、試聴用ファイルだけ境界に3 msランプをかけた。raw DSPにゲインやランプは焼き込んでいない。[manifest](audition_manifest.csv)に区間・ゲイン・SHA-256を記録。[表示ラベルの対応表](blind_key.csv)は評価後に見ること。

Phase 37のMIX/Drums全体の既存ブラインド試聴では、ユーザーが方式Bのアタックを支持し、前響き・二重化・音の詰まり・定位差は気にならないと回答済み。Phase 38の白色ノイズ2.00倍速では、表示B（実装A）が表示A（実装B）より短いと知覚されたが、どちらが自然かは判断できないという評価だった。Vocal/Guitar/Bassなど他の楽器では人間の耳で差が分からないかもしれない、という評価も記録した。これを「Bが優位」と読み替えず、**正式採用は保留**する。今回、欠落ではなく時間包絡の変化が主因と判明したため修正版Cは実装していない。検証なしの時間位置補正は、Phase 37 Bの好評だったMIX/Drumsアタックを壊し得る。
