# Phase 13：0.50倍速 Offline-Equivalent Streaming Engine

## 範囲と実装

Phase 12のExperimental 3500を、既知のWAVと固定速度0.50に限定してC++ストリーム出力へ移した。元の `ChunkedTimeStretchEngine`、オフラインDSP、Phase 10/10.1、Golden WAVは変更していない。Phase 13はオフライン処理順を独立したクラスへ固定した実験経路であり、新しい音質処理はない。独立コピーであるため、将来オフライン処理を変更した場合は差分確認が必要。

`Phase13StreamingEngine::processFile(input, sink, blockFrames)` は、まず入力全体を走査してMidの過渡音イベント、精密アンカー、0.50用TimeMap、リセット時刻を確定する。その後、Low 8192/2048、Mid 4096/1024、High 1024/256を同じTimeMapで進め、各経路の位相状態と窓二乗正規化OLAを処理し、LP250とLP3500の既存FFT畳み込みを同じ順序で加算する。出力は8192〜65536フレームのplanar floatブロックをコールバックへ渡す。クラスは全長出力バッファとWAV writerを持たない。サンプルの読み出し、FFT、OLA、FIRは既存のリング／キャッシュ方式を維持する。CLI `phase13_stream` はコールバックから無加工float WAVを逐次書き出す。0.50以外やExperimental 3500の固定設定から外れる構成は拒否する。

このAPIは既知ファイルを対象とするオフライン互換のストリーミング試作である。AVAudioEngine、音声コールバック、任意のライブ入力、速度変更、シークには対応しない。事前解析は最初の出力より前に完了する。Phase 10.1の有限先読みTimeMapは使わない。

## Goldenとの結果

Phase 12で凍結した5入力とraw GoldenのSHA-256を先に照合した。Phase 13の8192・16384フレーム出力を各Goldenと比較した結果、**10件すべてでWAV全体のSHA-256が一致し、最大サンプル差0、出力長一致**。目標の `1e-5` 未満を満たす。無加工のfloat WAVを比較しており、試聴用ゲインは適用していない。Goldenで有限と確認された出力とのバイト一致により、NaN/Infもない。

`scripts/phase13_verify.py` は入力・Goldenハッシュ、出力SHA-256、長さ、TimeMapハッシュ、サンプル差、段別診断値を再検証する。生成されたWAVと詳細診断CSV/JSONは `results/phase13/` に保持するがGit管理外である。元のGoldenは再生成・上書きしない。最終検証実行の所要時間は10秒入力で約1.55〜1.74秒、45秒入力で約6.30〜7.60秒。診断ハッシュ計算を含むMac上のオフライン値であり、リアルタイム期限の評価には使わない。

精密アンカーを実際に通る補助クリック（19イベントすべてでアンカー採用）も0.50倍速で処理した。両ブロックサイズでPhase 13のTimeMapハッシュは `8916701400269699567`、出力96万フレーム、Goldenとの最大サンプル差0、WAV SHA-256一致だった。

## 段別差分

各解像度・各チャンネルのFFT出力、位相制御後スペクトル、IFFT出力、OLA確定サンプル、およびLP250・LP3500それぞれのFIR出力と最終加算を処理順にハッシュ化した。出力ブロック8192と16384の比較では、**5入力と補助クリックのすべてで全15診断ハッシュが一致**した。TimeMapはGolden manifest／補助参照のハッシュと6件すべて一致。これはチャンク境界によるFFT、位相、OLA、両FIRの状態差がないことを確認する検査である。合成クリックを含む1秒のステレオ単体テストでも、オフライン参照と両ブロックのWAVがバイト一致した。

**測定の限界：** 凍結Goldenには途中段のスペクトル・位相・OLA・FIRの値が保存されていないため、各途中段についてGoldenそのものとの数値最大差は算出できない。段別の一致はPhase 13の異なるチャンク分割間で測り、オフラインとの差は最終WAVで測った。途中段でGoldenとの直接差分が必要になった場合は、正本を変更せず、オフライン実装の診断用ビルドから基準トレースを採取する。

## ビルド・回帰・保管ゲート

Releaseビルドは成功。`ctest --test-dir build --output-on-failure -j4` は**22/22成功、失敗0**（122.72秒）。Phase 13単体テストは、オフライン参照および8192/16384ブロックのバイト一致、長さ、TimeMap、段別診断値、0.50以外の設定拒否を確認した。

Goldenと凍結入力のSHA-256は一致している。2026-10-10に別媒体のUSB上へAES-256暗号化イメージを作り、USB側のイメージをマウントして別ディレクトリへ復元した。**二次保管・復元ゲートは完了**。54ファイルの個別ハッシュ、Golden 15本、精密アンカー補助WAV、試聴用15本の検証が成功した。詳細は [保管レポート](CUSTODY_REPORT.md)。途中段のGolden基準トレースは未取得であり、その数値差については本レポートの測定範囲を超える。
