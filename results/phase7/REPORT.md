# Phase 7 — PVSOLA 型の周期的位相再同期（試作）

## 判定

Mid 4096/1024 経路に、出力の重なり部分と入力候補の波形相関に基づく位相再同期を追加した。**既定は OFF**。Phase 5.3 High を音質基準として維持し、Phase 6 の部分音追跡も既定 OFF の実験機能として残した。14 件の全テスト、長さ、NaN/Inf、OFF の厳密回帰は成功した。

**現時点では Phase 7 を採用しない。** 実 Vocal では調波振幅のフレーム間変動が男女各3区間の 0.75x／0.50x、計12条件すべてで増えた。ステレオ幅も一部で縮んだ。強制再同期点のサンプル微分値にも増加が見られる。watery／phasy 感が聴感で明確に減るか、子音・定位・クリックに問題がないかは、人による A/B 試聴が必要である。

## 実装と設定

- `--pvsola on --chunked on --phase-locking on --quality high` に加え、過渡検出、Adaptive TimeMap、Precise Anchoring、ステレオ入力では Stereo Coherence を有効にして試す。Phase 6 `--partial-tracking on` との併用は禁止。これらの前提は設定検証でも確認する。試作 ON は逐次処理 API 専用で、全長 `processOffline` は明示的に拒否する。
- 基準設定は再同期間隔 **120 ms**、探索 **±10 ms**、最小正規化相関 **0.65**。CLI でそれぞれ変更可能。実際の周期は解析ホップに丸め、48 kHz／1024 hop では約6フレーム（128 ms）。
- Mid の解析スペクトルについて、150 Hz～6 kHz の強い局所ピーク付近の電力比を tonality とし、**0.55 以上**のみ候補にする。ピークは局所平均振幅の3倍以上。過渡リセットの前後 **±3 フレーム**は候補を抑制する。音程・拍位置を決める TimeMap、過渡イベント、LP250 クロスオーバー、Low 8192/2048、Stereo Coherence は維持する。
- 相関は、Mid の重ね合わせバッファで既に合成済みの出力と入力候補の**左右平均波形**で計算する。8サンプル差分で低域の影響を弱め、重なりの 256～1276 サンプルを4サンプル刻みで比較する。探索は16サンプル刻みの粗探索後、最良点周辺を1サンプル刻みで再探索する。ここでの差分は厳密な 150 Hz～6 kHz 帯域フィルタではない。
- 採用した入力候補の FFT の解析位相を、**予定フレームの振幅**と組み合わせる。元のピーク領域で Identity Phase Locking し、出力位相と `PhaseVocoder` の位相状態を一致させる。次フレームでは、再同期した bin だけ実際の解析距離 `hop - offset` を使う。候補スペクトルが弱く再同期しなかった bin は通常の hop のままにする。出力フレームの開始位置と最終サンプル数は変更しない。
- 入力候補用スペクトルと照合用の状態は事前確保し、フレームループ内で巨大 FFT や動的な作業バッファの生成は行わない。デバッグ時の `pvsola_resync.csv` は、frame、inputSample、outputSample、scheduledResync、resyncApplied、searchOffsetSamples、correlation、tonality、transientSuppressed を記録する。

## 入力と A/B

男女 Vocal は 10 秒ずつ3箇所を使用した。女性は入力 15～25、103～113、145～155 秒、男性は 43～53、90～100、146～156 秒。区間は 16 kHz に縮小した入力の調波ピーク濃度を10秒窓で走査し、互いに20秒以上離れた上位候補から選んだ。**実際に持続母音・息を含むかの最終確認は試聴が必要**である。Mix と Bass は 90～135 秒、Drums と Guitar は 90～110 秒。同じ入力切り出し・同じゲインで 0.75x／0.50x の OFF/ON を生成した。全 WAV と条件は [manifest.csv](manifest.csv) に記録している。

## 人工信号と間隔比較

合成母音、±20 cent／6 Hz のビブラート、白色雑音、スネア状バースト、シンバル状減衰雑音、歪み調波、残響尾部を 0.75x／0.50x で比較した。雑音・スネア・シンバル・残響尾部では再同期 **0 回**。歪み調波は43回／6秒であり、tonality gate は周期的な歪みを除外しない。詳細は [人工信号指標](artificial/manifest.csv)、[クリック指標](artificial/click_metrics.csv)、[母音変動](artificial/vocal_modulation.csv)。

ビブラート深さ（FFT で推定した変動半幅、OFF→ON）は 0.75x で **13.91→14.22 cent**、0.50x で **15.58→15.94 cent**。振幅変動係数はそれぞれ 0.03876→0.03824、0.05412→0.04953 で、本来のビブラートを平坦化していない。値は [vibrato_metrics.csv](artificial/vibrato_metrics.csv)。合成母音の調波変動 RMS は 0.75x で4.631→4.700 dB、0.50x で4.544→4.543 dB、包絡変動は0.50xで0.05224→0.05793。

80／120／160 ms 間隔を女性・男性各1区間、0.50xで比較した。[全結果](interval/vocal_modulation.csv)。女性の調波変動 RMS は OFF 7.800 dB に対し ON で8.003／8.148／8.170 dB、男性は OFF 5.615 dB に対し5.787／5.786／5.739 dB。クリック指標と包絡変動を合わせても**明確な最適点は得られず、120 ms を実験時の基準値のまま維持**する。160 ms を既定に変更しない。

## 再同期点の波形変化

同じ時刻の OFF/ON を比較し、再同期点の前10 ms～後30 msにおける最大サンプル微分、前後20 msの RMS 段差、隣接窓のスペクトル差を測定した。[全結果](click_metrics.csv)。

- 女性2・0.50x の微分値90パーセンタイルは **0.1461→0.1487**、スペクトル差中央値は **0.02546→0.02990**。
- 男性2・0.50x は **0.02571→0.02980**、スペクトル差中央値は **0.00805→0.00816**。
- Mix・0.50x は微分値 **0.31645→0.31645**、Drums・0.50x は **0.28828→0.31218**。
- 合成母音・0.50x の微分値90パーセンタイルは **0.02094→0.02266**。白色雑音・スネア・シンバル・残響尾部は再同期0回なので、この測定に該当する再同期点はない。

明らかな発散や大振幅の単発クリックは単体試験では見つからなかった。ただし複数の実素材で微分値が増えており、**クリックなしと聴感上断定はできない**。

## 回帰、CPU、メモリ

- Phase 7 OFF と保存済み Phase 5.3 High は Bass／Mix／女性／男性 × 0.75x／0.50x の**8条件すべてで最大サンプル差0**（[off_regression.csv](off_regression.csv)）。
- ON/OFF の各ペアで TimeMap、過渡イベント数、出力サンプル数が一致。生成した WAV に NaN／Inf なし。逐次書き出し 8192／65536 サンプルの ON 出力差は単体試験で0。
- 実音源の ON/OFF 20 ペアで出力 RMS 差の最大絶対値は約 **0.18 dB**。異常な全体ゲイン変化は見られなかった。
- CPU 秒（OFF→ON、同じ10秒区間の平均）は女性0.75xで1.041→1.120、0.50xで1.080→1.225、男性0.75xで1.039→1.139、0.50xで1.096→1.169。Mix 45秒の0.50xは4.551→5.088秒。単独実行の計測で、環境のばらつきを含む。
- Peak RSS は OFF/ON とも約 **14 MiB**。Mix 0.50xで13.86→13.95 MiB。入力長に比例する大きな保持バッファを追加していない。
- `cmake --build build -j4` 成功。`ctest --test-dir build --output-on-failure` は Phase 1～7 の **14/14 成功**。Phase 7 単体試験では再同期適用、過渡抑制、有限値、長さ、ステレオ相関、chunk サイズを検証した。

## 聴感で確認する点と残る問題

同じ音量で、女性・男性の各3区間の持続母音の watery／phasy／chorus 感、母音の近さ、ビブラート、息と子音を確認する。次に Mix の声の中央定位、Drums のスネアとシンバル、Guitar の粗さ、Bass の揺れを確認する。実 Vocal の変動増加とステレオ幅の変化が聴感にどう現れるかが採否の決め手。現在の強制再同期にはクリックや周期的な粗さの可能性が残り、soft resync は未実装である。

音質改善が主観評価で明確になるまで Phase 5.3 High を維持する。Pitch Shift、Swift、実時間再生には進まない。
