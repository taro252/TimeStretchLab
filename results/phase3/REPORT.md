# Phase 3 — Transient Detection + Phase Reset

## 実装

- `TransientDetector` がオフラインの事前解析で左右合成振幅 `sqrt(|L|² + |R|²)` を使い、全フレーム共通のリセット位置を決めます。モノラルではそのままの振幅です。
- 各 bin の `log(1 + 10 × magnitude)` の正のフレーム差を合計し、現在フレームの対数振幅和で割った値を spectral flux とします。DC/Nyquist は除外します。
- 直前 12 フレームの flux の中央値と MAD（中央値からのずれの中央値）を使い、`threshold = max(0.02, median + 3 × MAD)` とします。局所最大、強度 0.25 以上、2 フレームの cooldown、フレーム全体の振幅増加を要求します。
- 前後フレームを見た上で、既定では検出位置の 1 フレーム前へリセットを置きます。前フレームがほぼ無音なら検出フレーム自体に置きます。ファイル末尾のゼロ詰めに触れるフレームは検出対象外です。
- リセット時は有効 bin の合成位相・前回解析位相・初期化状態を現在の解析位相に合わせ、その後にピーク位相固定を適用します。低振幅 bin のリセットは維持します。左右は同じフレームでリセットしますが、使用する解析位相は各チャンネル固有です。
- `--transient off` は Phase 2 と同一で、保存済み Phase 2 正弦波との最大サンプル差は 0 です。Debug CSV は `--debug-csv directory` の `transients.csv` に、flux・エネルギー・閾値・強度・検出・適用位置・共有チャンネル数を記録します。

## 人工信号と単体テスト

Phase 1～3 の単体テストは 4/4 成功。人工信号の詳細は [artificial/metrics.txt](artificial/metrics.txt) です。

| 信号 | 検出数 | Phase 2 / Phase 3 の比較 |
| --- | ---: | --- |
| 単独インパルス | 1 | 波形・アタック幅は同一。0.75x で約 0.70 ms、0.50x で約 2.65 ms。 |
| 120 BPM クリック列 | 8 | 波形は同一。0.50x でクリック間隔は約 2 倍、最大誤差約 30 ms。 |
| ドラム状信号＋持続音 | 3 | 波形は変化。0.75x アタック幅は約 140→143 ms、0.50x は約 142→146 ms で、改善は確認できず。 |
| 440 Hz 定常正弦波 | 0 | ON/OFF 差 0。 |
| ゆっくり音量変化する正弦波 | 0 | ON/OFF 差 0。 |

単独インパルスとクリックは無音から始まるため、Phase 2 が既に各 bin の位相を初期化します。今回の位相リセットだけではアタックを短くできないという限界が明確です。ドラム状信号で 1 回のアタックに 3 回検出が出たことは過剰リセットの候補です。

## 6 素材の実音源 AB

`real/` に Phase 3 ON の 0.75x・0.50x WAV を保存しました。比較元の Phase 2 ON は `../phase2/real/stems/` にあります。`real/manifest.csv` は対応表、`real/processing_metrics.txt` は処理時間と検出数、`real/metrics.txt` は出力特性、`real/comparison.txt` は同じサンプル位置の波形差です。全 12 出力で期待サンプル数と一致し、NaN/Inf はありません。

次の表は 1 秒ごとの左右波形相関の中央値です。矢印の左が Phase 2、右が Phase 3 です。

| 素材 | 検出数 | 0.75x Phase 2 → 3 | 0.50x Phase 2 → 3 |
| --- | ---: | ---: | ---: |
| Mix | 893 | -0.019 → 0.533 | -0.007 → 0.414 |
| Bass | 863 | 0.068 → 0.966 | 0.033 → 0.940 |
| Guitar | 605 | 0.065 → 0.757 | -0.096 → 0.604 |
| Piano | 439 | -0.032 → 0.655 | -0.005 → 0.462 |
| Vocal | 457 | -0.005 → 0.225 | 0.000 → 0.127 |
| Drums | 1047 | 0.050 → 0.703 | 0.016 → 0.425 |

Phase 3 は Phase 2 の強い左右非相関を緩和しました。ただし入力相関には達しておらず、特に Vocal の中央定位はなお弱い数値です。波形差の実効値は素材に応じて約 0.17～0.33 あり、頻繁な位相リセットによるざらつき、低音の不連続、ピッチ揺れは試聴が必要です。クリックやアタック明瞭度の改善を数値だけで確認できたわけではありません。

10 秒の人工信号処理は 0.1 秒前後です。実曲では Mix の Phase 2 ON が約 9.4 秒、Phase 3 ON が約 10.0 秒／290 秒入力でした。各ファイルの処理時間は `real/processing_metrics.txt` を参照してください。

## 試聴用 WAV

`real/audition/` に、各素材の元音源 60～90 秒に対応する Phase 3 出力を保存しました。Phase 2 の同一区間は `../phase2/real/stems/audition/` にあります。全ファイルに同じ固定ゲイン 0.4 を適用し、試聴用 Phase 3 WAV の最大ピークは 0.647 未満、1.0 超えと NaN/Inf はありません。

次の作業判断では、Kick/Snare とピッキングのアタック、Vocal の子音、低音の不連続、ステレオ中心の聴感を確認する必要があります。Multi-resolution、Adaptive Local Time Mapping 等は実装していません。
