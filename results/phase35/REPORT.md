# Phase 3.5 検証結果

## 実装

`--transient on --adaptive-time-map on` で有効。Phase 3 の検出フレームから、閾値超え・強度 0.25 以上・エネルギー増加の候補を作ります。4 フレーム以内の候補を統合し、強い立ち上がり後のエネルギーが 20% 未満の候補は 12 フレーム以内なら余韻として統合します。各イベントは最大 spectral flux のフレームをピークとして保持し、位相リセットはそのピークで 1 回だけ適用します。合成位相・前回解析位相・初期化状態の更新と、その後の Peak Phase Locking は Phase 3 の処理を使います。

イベントの前 2 フレーム、後 5 フレームに raised cosine の滑らかな包絡を設け、ピークの局所時間比を 1.0 にします。イベント間の持続区間で不足した伸縮量を補償し、イベントピークを元の全体テンポの位置に固定します。補償比の上限は全体時間比の 1.5 倍です。各フレームの合成開始位置は累積した局所ホップを丸めて求め、位相伝播には実際の開始位置差を渡します。最終出力サンプル数は従来と同じ `round(inputSamples × timeRatio)` です。イベント一覧と時間配置は左右で共有し、位相解析は各チャンネルで独立です。

`event_map.csv` は `frameIndex,flux,threshold,eventId,eventStrength,isTransientRegion,localTimeRatio,synthesisStart,resetApplied,sharedChannels` を記録します。人工ドラムのデバッグ例では、リセットはフレーム 42 の 1 回、局所時間比は 1.0～2.02439（0.50x）でした。

## テスト

ビルド成功。CTest は Phase 1、Phase 1 検証、Phase 2、Phase 3、Phase 3.5 の **5/5 成功**。Phase 3.5 を無効にした既存 Phase 1～3 の経路を維持しています。定常 440 Hz 正弦波は 0 イベントで、Phase 3 と Phase 3.5 の出力はサンプル単位で同一でした。ステレオのクリック列は 8 イベントで、左右 1:0.5 の振幅比の最大誤差は 0 でした。イベントピークと全体の合成位置の誤差は各 1 サンプル以内です。

以下の「幅」は、アタック周囲 ±120 ms で絶対振幅がピークの 10% 以上のサンプル数です。ドラムでは減衰音も含むため、立ち上がりだけの厳密な幅ではありません。詳細は [人工信号の測定値](artificial/metrics.txt) を参照してください。

0.50x のクリック間隔の最大誤差は 12.4 ms でした。ドラムのアタックから 250 ms 以上離れた場所の最大サンプル間変化は 0.0021 以下で、追加の大きなクリックは見つかりませんでした。人工ドラムの入力と 3 方式のアタック周辺 ±150 ms は [0.75x 波形 CSV](artificial/drum_075_waveform.csv)、[0.50x 波形 CSV](artificial/drum_050_waveform.csv) に保存しています。

## 実音源 AB

Mix と Bass の全長を 0.75x／0.50x で処理し、Phase 2・3・3.5 の同一区間を固定ゲイン 0.4 で [試聴用 WAV](real/audition/) に保存しました。3 方式とも元音源 60～90 秒に対応する区間です。全 12 試聴用 WAV は有限値でピーク 1.0 未満です。全長の Phase 3.5 WAV は `real/` にあります。全長の出力サンプル数は期待値と一致し、NaN/Inf はありません。

| 素材 | 0.75x イベント | 0.50x イベント | 1 秒ごとの左右相関中央値 0.75x、Phase 2→3→3.5 | 同 0.50x |
| --- | ---: | ---: | --- | --- |
| Mix | 844 | 844 | -0.019 → 0.533 → 0.687 | -0.007 → 0.414 → 0.578 |
| Bass | 761 | 761 | 0.068 → 0.966 → 0.997 | 0.033 → 0.940 → 0.995 |

Mix の 0.75x／0.50x 処理時間は 9.74／11.69 秒、Bass は 14.89／12.77 秒でした。Phase 3 の Mix は約 10 秒、Bass は約 10.4 秒です。詳細は [処理時間とイベント数](real/processing_metrics.txt)、[全長 WAV 指標](real/metrics.txt)、[試聴用 WAV 指標](real/audition/metrics.txt) にあります。

## 残る問題

人工ドラムの 0.50x 幅は Phase 3 より 1.4 ms 短いものの、Phase 2 より 3.4 ms 長く、大きな改善とは言えません。全 bin 位相リセットを継承しているため、Bass の低域の不連続、ピッチ揺れ、Mix の粗さやアタックの聴感上の明瞭さは試聴が必要です。左右相関の改善だけでは音質改善を証明できません。Mix の無補正ピークは 1.0 を超えるため、実際の再生・納品時にはレベル管理が必要です。

弱い余韻を 12 フレームまで同一イベントに統合するため、短い間隔の独立した打撃を結合して見逃す可能性があります。一方、Mix は約 290 秒で 844 イベントあり、過剰検出の可能性も残ります。今回、Multi-resolution、Advanced Stereo Coherence、Pitch Shift、Real-time Streaming、Swift integration は実装していません。
