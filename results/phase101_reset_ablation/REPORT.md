# Phase 10.1 R−：全 bin 位相リセットだけを無効化

## 実験の範囲

Phase 10.1 の全機能有効版（F）と、過渡音イベント時の**全 bin 位相リセットだけ**を止めた R− を比較した。128 ms 先読み、同じ入力 WAV、速度、ブロック長、ゲイン、出力形式を使用。イベント検出、時間写像、伸張量返済、精密アンカー、ピーク位相ロック、Mid/Low、ステレオ処理は共通。Phase 10 の線形モードの既定値は変えていない。Phase 5.3、9C、および保存済み Phase 10.1 WAV は変更していない。

`RealtimeTransientConfig::enablePhaseReset` は過渡音モードでのみ効く診断用スイッチで、既定値は `true`。CLI では `--mode transient --phase-reset off` が R−。両解像度と左右チャンネルのリセット適用を同時に止める。位相追跡の低振幅 bin 初期化や `reset()` 全体の動作は変更しない。

## 生成物と再現方法

- `results/phase101_reset_ablation/ab/`：8入力 × 0.50/0.75倍 × F/R− の32本の float WAV。
- `comparison.csv`：長さ、イベント一致、最大・実効値のサンプル差、RMS、ピーク、短時間音量変動、人工音のアタック指標。
- `manifest.csv`：入力、出力、SHA-256。`events/`：各出力の過渡音イベント CSV。
- `listening/`：ピークが1を超えた Mix に限り、F/R− の両方へ**同じ**ゲインを掛けた試聴コピー。0.50倍は各0.512995倍、0.75倍は各0.607888倍。元の DSP 出力は `ab/` に保持。
- `scripts/phase101_reset_ablation.py` を NumPy がある Python で実行すると再生成できる。入力は既存の `results/phase101/artificial/`、`results/phase101/real/` と `results/phase9a/` の保存済み WAV。古い結果ディレクトリへは書き込まない。

## 成立性と回帰

- 新しく生成した F は、既存の Phase 10.1 の同名素材6種類 × 2速度、計12本の WAV と**バイト単位で一致**。純母音と息混じり母音には旧版の対応 WAV がないため、この照合の対象外。
- F と R− のイベント CSV、イベント数、精密アンカー数、最終・最大伸張債務は、全16組で一致。検出と時間写像が同じ条件で動いたことを確認した。全出力でサンプル長は `round(input frames / speed)`、非有限値なし。クリック列は各条件で19イベント、女性15、男性7、Mix34。
- `cmake --build build -j8` 成功。`ctest --test-dir build --output-on-failure` は既存 Phase 1〜10.1 を含め **21/21 成功**（161.82秒）。追加テストで 0.50/0.75 倍のイベント一致、出力長、処理中の計数対象 C++ ヒープ確保0、入力ブロック分割に依存しない結果を確認。

## 客観指標

次表は0.50倍、48 kHz。同じ時間写像なので、出力同士のサンプル差は主に位相リセットの有無による波形差を示す。ただし**最大サンプル差の大きさは音質の良し悪しではない**。ピーク値が1を超える float WAV は再生経路でクリップする可能性があり、試聴時に注意する。

| 素材 | 最大サンプル差 | F/R− RMS | F/R− ピーク | 評価上の観察 |
| --- | ---: | ---: | ---: | --- |
| クリック列 | 0.0141 | 0.00332 / 0.00332 | 0.861 / 0.853 | 最大間隔誤差はいずれも15.13 ms。位相リセットだけではこの時間誤差は直らない。 |
| 人工ドラム | 1.042 | 0.04268 / 0.04266 | 0.542 / 0.541 | 立ち上がり中央値は7.56 / 9.33 ms、前20 msエネルギーは0.02785 / 0.03467。R− が一様に改善したとは言えない。 |
| 短い雑音バースト | 0.0475 | 0.01299 / 0.01299 | 0.561 / 0.590 | 10→90%立ち上がり中央値は13.35 / 2.06 ms。ただし雑音の局所最大に依存する指標で、聴感の代理にはならない。 |
| 女性ボーカル | 1.044 | 0.12931 / 0.12952 | 0.800 / 0.773 | 50 ms窓の有声音量変動の中央値は0.479 / 0.513 dB。水っぽさの改善は未判定。 |
| 男性ボーカル | 0.381 | 0.02163 / 0.02209 | 0.247 / 0.207 | 同じ音量変動の中央値は0.522 / 0.460 dB。母音の安定性は要試聴。 |
| Mix | 2.340 | 0.20828 / 0.21146 | 1.852 / 1.646 | R− でもピークが1を超える。クリップとアタックの聴感を分けて確認する。 |
| 純母音 / 息混じり母音 | 0 / 0 | 同一 | 同一 | いずれも検出イベント0。リセット経路に入らないため、R− は無効果。 |

0.75倍のクリック列では F/R− とも間隔誤差は実質0 msだが、前20 msエネルギーは `1.7e-7 / 8.2e-6`、立ち上がり指標は `0 / 7.83 ms` となり、R− でアタック前の成分が増えた。数値から一律にリセットを廃止すべきとは言えない。0.50倍の人工ドラムでも R− は前響きが増えている。全測定値は `comparison.csv` に保存した。

## 暫定評価と次の判断

R− で実音源の波形は大きく変わったが、RMSや単純な音量変動には一方向の改善がない。人工音でも改善・悪化が混在し、0.50倍クリックの間隔誤差は不変。**全 bin 位相リセットだけを Phase 10.1 の主因と結論づける証拠はない**。特にイベントがない純母音の水っぽさは、この切替で説明できない。

次の判断には F/R− の女性・男性ボーカルを同一音量で試聴し、アタック、水っぽさ、母音の安定性を個別に記録する必要がある。R− が安定して良く聞こえなければ Phase 10.1 の追加調整を続けず、Phase 11 の独立した音質研究へ進める。Phase 11 の開始は Phase 10.1 の全原因特定を条件としない。今回は Guided Phase Advance や他の Phase 11 DSP を実装していない。
