# Phase 2 — Peak-based Phase Locking 検証

`metrics.txt` に人工信号の速度別 ON/OFF 測定値を保存しています。各 `*_off.wav` は Phase 1、`*_on.wav` は Phase 2 です。両者は同じ入力・速度・WAV 形式を使い、ピーク正規化をしていません。

## 自動検証

- Phase 1 保存済み正弦波との OFF 経路の最大サンプル差: 0（0.75x、0.50x）。
- locked phase を内部 synthesis phase state にも保存。周辺 bin が次フレームでピークになる回帰テストを通過。
- 48 kHz・437.3 Hz 正弦波の主周波数: ON/OFF、0.75x/0.50x の全条件で 437.3 Hz。
- 単一正弦波の 0.50x 実効値: OFF 0.3243、ON 0.3534（入力理論値 0.3536）。
- 110～660 Hz 高調波の 0.50x 実効値: OFF 0.1543、ON 0.1676。ON の各高調波測定振幅は生成時の設定値から約 0.001 以内。
- 400→500 Hz 移動正弦波では主ピーク bin が 37→46 へ 9 回移動。ON の最大隣接サンプル差は 0.75x で 0.0395、0.50x で 0.0358。20 ms 実効振幅の最大/最小比はそれぞれ 1.0192、1.0194 で、測定上の大きな click/crack や周期的音量変動はなし。
- 440/470 Hz の近接 2 音は両方の周波数成分を維持。ただし ON 0.50x の最大隣接サンプル差は 0.0664、OFF は 0.0391。
- ノイズ、無音、近接 2 音を含む全出力で NaN/Inf、3.0 を超えるピークはなし。無音の ON 出力は全サンプル 0。
- 10 秒モノラル人工音の処理時間は、おおむね OFF 0.12～0.14 秒、ON 0.14～0.17 秒（この Mac での測定）。

## 音質評価の限界

これらは周波数・振幅・サンプル差などの客観測定です。音の芯、ボーカルの水っぽさ、定位、クリックの聴感については試聴が必要です。6 種類の実音源 AB 比較は [real/stems/REPORT.md](real/stems/REPORT.md) に記録しています。先に提供された `BELIEVE.wav` の比較は [real/README.md](real/README.md) にあります。

次の音質課題は、実録音の ON 出力で見られた大きな左右相関の低下、近接音の 0.50x で見られた波形変動、ノイズの 0.75x で ON 実効値が OFF より約 34% 高い点です。過渡音の処理は、この Phase には含みません。
