`audition/` には原曲 60～90 秒と、その同じ内容に対応する各出力区間を収めました。原曲は 30 秒、0.75x は 40 秒、0.50x は 60 秒です。再生環境でのクリップを避けるため、**全ファイルに同じ固定ゲイン 0.4** を掛けています。これは各ファイル別のピーク正規化ではありません。試聴用 WAV はすべてピーク 1.0 未満で、詳細は `audition/metrics.txt` にあります。
