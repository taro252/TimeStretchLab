# Phase 6 — 部分音ピーク追跡の実装と検証

## 結論

Phase 5.3 High（Low 8192/2048、Mid 4096/1024、LP250）に、Mid 経路だけの部分音ピーク追跡を追加した。`--partial-tracking on` で試せる。既定は OFF のまま。人工信号ではビブラートと調波の安定性をほぼ維持し、実音源でも長さ・ステレオ指標に重大な退行はなかった。一方、持続母音の変動指標に明確な改善はない。**watery / chorus 感が聴感で減ったかは未判定であり、Phase 6 を新たな既定音質として採用していない。**

## 実装

`PartialTracker` が Mid の `PhaseLocker` で検出したピークに track ID を付ける。ステレオでは左右を合成したピーク地図で ID を共有し、位相状態は左右別々に保持する。低域経路には適用しない。過渡イベントで従来の位相リセットが起こると、track も初期化する。既存の TimeMap、過渡イベント、位相ロック、ステレオ位相補正、逐次処理は維持する。

- 対象：150 Hz～6 kHz、フレーム最大ピークの 1% 以上、ピーク／近傍平均振幅が 3 以上。
- 一致条件：周波数差が **80 cent 以下かつ 1.5 FFT bin 以下**。費用は `cent差/80 + Hz差/(1.5 bin) + 0.25×|log(振幅比)| + 0.12×欠落フレーム数`。候補 track のうち最小費用を貪欲に選び、1 track を同一フレームの複数ピークに割り当てない。
- 新規ピークには新しい ID を与え、欠落は 2 フレームまで許容する。位相の適用は track の 3 フレーム目から行うため、短命なピークは従来処理のまま。
- 追跡中の位相は bin ではなく track に保持する。旧 bin の解析位相差から瞬時周波数を推定し、bin が移った場合は**同一フレーム内の旧 bin→新 bin の解析位相差**で位相基準を移す。これを省くとビブラート深さが約 2 倍になったため、移動補正は必須だった。周辺 bin は track の位相を基準に Identity Phase Locking し、`PhaseVocoder` の内部位相状態にも反映する。ステレオ位相補正後のピーク位相を次フレームの track 状態へ同期する。
- track pool、候補一覧、bin 対応表を事前確保し、フレーム処理中の動的確保を避ける。最大 pool サイズは FFT の非負周波数 bin 数。

## 回帰・長さ・計算量

- 追跡 OFF は保存済みの Phase 5.3 High 出力と、8 条件すべてで最大サンプル差 **0**、差のあるサンプル数 **0**（`real/off_regression.csv`）。
- ON/OFF の各ペアは TimeMap、過渡イベント数、出力長が一致。45 秒の Bass/Vocal は 0.75x が 60 秒、0.50x が 90 秒。Mix は 44.999 秒入力から 60／90 秒。16 WAV の NaN／Inf はなし。
- 45 秒素材を各条件で処理した平均 CPU 時間は OFF 4.734 秒、ON 4.727 秒、平均 wall 時間は 4.768／4.762 秒。並行実行のばらつき内で、単独実行の厳密な性能差とは解釈しない。最大 RSS は OFF 約 13.94 MiB、ON 約 14.19 MiB。前処理や OS キャッシュを含むプロセス RSS である。
- 追跡 ON の全長処理と逐次処理の単体比較は最大サンプル差 `2.98e-8`。
- `peak_phase_discontinuity` は位相累積式との内部整合性残差で、実録音の最大は `7.18e-13 rad`。**耳に聞こえる位相の飛びを直接測る独立指標ではない。**

## A/B 試聴で確認する点と残る問題

女性／男性 Vocal の持続母音で watery・chorus 感、母音の輪郭とビブラートをまず比較する。子音と息成分、中央定位も聴き、Mix では声の中心と残響幅、Bass では周期的な揺れを確認する。0.50x を優先し、0.75x でも同じ箇所を比較する。音量差で判断が偏らないよう同一再生音量を使う。

実 Vocal の track 寿命は短く、追跡適用も対象ピークの約 50～57% に限られる。再誕生時の位相は従来処理から始めるので、短い母音の全域で改善する保証はない。個別の母音でのクリック、微細なうねり、子音への影響は WAV の聴感確認が必要。現時点では **Phase 5.3 High を既定に維持**する。
