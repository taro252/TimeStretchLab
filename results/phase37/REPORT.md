# Phase 3.7 — サンプル単位の過渡イベント位置補正

## 実装

`--transient on --adaptive-time-map on --precise-anchoring on` で有効です。イベント検出・統合、時間配置の包絡、位相リセット、ピーク位相固定、左右共通イベント時刻は Phase 3.5 と同一です。Phase 3.6 の選択的 bin リセット、低域重み、複素ベクトルによる柔らかい位相リセットは使いません。`--selective-reset on` との併用は禁止しています。どちらも既定では OFF です。

新しい `TransientAnchorLocator` が、各イベントのピークフレーム付近（前 1～後 2 解析ホップ）の入力サンプルを調べます。左右がある場合は各サンプルの二乗エネルギーを合計します。最大サンプルの振幅と領域内の平均二乗振幅の比（crest factor）が 20 以上で、離れた次点ピークの振幅の 3 倍以上、かつ探索端でない場合だけ、サンプル位置を確定します。それ以外は `sampleOffset=0` として Phase 3.5 のフレーム位置へ戻します。

確定した入力位置を `absoluteInputSample = peakFrame × analysisHop + sampleOffset` とします。局所時間比が 1.0 のイベント内で、そのサンプルが `absoluteInputSample × globalTimeRatio` に出るよう、フレームの理想合成開始位置に `(globalTimeRatio − 1) × sampleOffset` を加えます。イベント間の持続区間で時間を補償するため、イベント時刻と全体の出力サンプル数を維持します。左右チャンネルには同じ位置補正を使います。`--debug-csv` の `anchors.csv` に確定／フォールバック、crest factor、入力位置、合成位置を記録します。

## ビルドとテスト

ビルド成功。CTest は Phase 1、Phase 1 検証、Phase 2、Phase 3、Phase 3.5、Phase 3.6、Phase 3.7 の **7/7 成功**です。詳しい人工信号の結果は [metrics.txt](artificial/metrics.txt) にあります。

| テスト | 0.75x | 0.50x |
| --- | ---: | ---: |
| 120 BPM クリック列の補正対象 | 8/8 イベント | 8/8 イベント |
| クリック間隔の最大誤差 | 0 ms | **0 ms** |
| 人工ドラムの補正対象 | 0/1 イベント | 0/1 イベント |
| 人工ドラム幅 Phase 3.5→3.7 | 136.168→136.168 ms | 145.079→145.079 ms |
| 定常正弦波のイベント | 0 | 0 |

ドラム幅はアタック周辺 ±120 ms で絶対振幅がピークの 10% 以上だったサンプル数です。人工ドラムの不確実なピークは補正せず、出力は Phase 3.5 と完全一致しました。ステレオの 1:0.5 振幅比を持つクリック列でも、左右出力の比の最大誤差は 0 でした。

## Mix・Bass の実音源

全長 Mix と Bass を 0.75x／0.50x で処理し、Phase 3.5 と Phase 3.7 の同一区間・固定ゲイン 0.4 の [試聴用 WAV](real/audition/) を作成しました。両素材とも信頼度条件を満たすイベントは **0 件**でした。したがって Phase 3.7 はフォールバックし、4 出力すべて [全サンプル比較](real/comparison.txt)で Phase 3.5 と完全一致しています。全出力の長さは期待サンプル数どおりで、NaN/Inf はありません。試聴用 8 WAV のピークも 1.0 未満でした。

| 素材・速度 | イベント数 | 補正対象 | 左右相関 Phase 3.5＝3.7 | Mid RMS | Side RMS | Side/Mid |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Mix 0.75x | 844 | 0 | 0.666 | 0.2113 | 0.0946 | 0.448 |
| Mix 0.50x | 844 | 0 | 0.539 | 0.1983 | 0.1085 | 0.547 |
| Bass 0.75x | 761 | 0 | 0.986 | 0.1187 | 0.0154 | 0.129 |
| Bass 0.50x | 761 | 0 | 0.974 | 0.1170 | 0.0177 | 0.151 |

Mid は `(L+R)/2`、Side は `(L−R)/2` の実効値です。数値全件は [ステレオ指標](real/stereo_metrics.txt)、処理時間・イベント数は [処理ログ](real/processing_metrics.txt)、試聴用指標は [試聴用 metrics](real/audition/metrics.txt) にあります。Phase 3.7 の処理時間は Mix が 9.29／9.57 秒、Bass が 10.00／10.09 秒（0.75x／0.50x）でした。

## 判断と制限

今回の完了条件であるクリック間隔 3 ms 以下、ドラム幅の非悪化、Bass／Mix のステレオ指標の非悪化、有限値、正確な出力長は満たしました。ただし実音源では補正対象 0 件なので、この条件の範囲では**音質もタイミングも Phase 3.5 から変わっていません**。明瞭な単発ピークを持つ別の実録音では変化する可能性があります。Phase 3.6 は実験機能として既定 OFF のままです。Stereo Coherence と Multi-resolution は実装していません。
