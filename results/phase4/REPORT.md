# Phase 4 — ステレオ位相の一貫性

## 設計

Phase 3.7 を基準とし、`--stereo-coherence on` のときだけ左右を同一フレームで解析・合成する。左右の入力スペクトルの振幅から `sqrt(magL² + magR²)` を作り、`PhaseLocker` で共同ピークと共同の所有領域を求める。各チャンネルは従来どおり瞬時周波数の推定、位相伝播、過渡イベント時の全 bin リセット、ピーク位相固定を行う。イベント検出、適応的時間配置、精密アンカーは Phase 3.7 のまま。Phase 3.6 の選択的リセットは既定 OFF で、今回の比較では使っていない。

各 bin の入力左右位相差は `IPD = wrap(arg(R) − arg(L))`。振幅の大きい方を基準チャンネルにし、もう片方の目標位相を `wrap(基準の合成位相 ± IPD)` とする。符号は基準が左なら `+`、右なら `−`。左右の出力振幅はそれぞれ元の値を維持する。基準位相と補正後の位相はボコーダーの内部状態にも反映する。

補正係数は次の積を 0〜1 に収める。`balance = 2 min(magL,magR)/(magL+magR+ε)`、`tonality = clamp((共同ピーク振幅/±8 bin の平均振幅−1.5)/3,0,1)`、`stability = clamp(1−|wrap(IPD−前フレームIPD)|/1.2,0,1)`。ピークから 3 bin 以内だけ対象とし、`weight = clamp(strength × balance × tonality × stability × (1+lowStrength×lowBlend),0,1)`。`lowBlend` は 150 Hz 以下で 1、150〜500 Hz で線形に 0 へ下がる。初回フレームや、どちらかが無音に近い bin は補正しない。周波数方向の IPD 平滑化は採用していない。

補正対象の位相は複素単位ベクトルで `arg((1−weight) exp(j independentPhase) + weight exp(j coherentTarget))` と混ぜる。位相角の直接線形補間は使わない。`--coherence-strength` の既定は 1、`--low-frequency-coherence` は 0.5。Phase 4 自体は既定 OFF。モノラルでは完全にバイパスする。フレーム処理中の追加 FFT と可変長メモリ確保はない。必要時だけ `--debug-csv` に bin 別の Mid/Side 振幅、位相差、係数、左右音量差を記録する。Mid/Side は診断にだけ使い、音声の変換経路には入れない。

## 試聴時の確認点と残る課題

同一ゲインのABでは、Bassの定位、Mixのボーカル・キック・スネアの中央像、残響の広がり、過渡音のクリックや揺れを確認する。数値上はMix 0.50xの Side/Mid が入力0.224に対し0.314で、広がりがなお残る。位相差の誤差も0にはならない。Phase 4 は過渡のアタック幅、伸縮による音色変化を改善対象にしていない。全長の浮動小数点WAVにはピーク1.0超のサンプルがあり、整数PCMへ変換する場合は別途ゲイン管理が必要。試聴用WAVは0.4倍にしてピーク1.0未満、有限値を確認した。今回、聴感による判定は行っていない。

Multi-resolution、Pitch Shift、リアルタイム処理、Swift連携には進んでいない。
